# 편집 방침: 의도를 먼저 고정한다

작업이 의도와 어긋나는 이유는 대개 실력이 아니라 **의도가 어디에도 안 적혀 있어서**다.
착수 전에 여섯 칸을 채운다. 못 채우는 칸이 있으면 그 칸이 먼저 물어볼 질문이다.

## 여섯 칸

| 칸 | 묻는 것 |
|---|---|
| 결정권자 | 이 산출물을 보고 결정할 사람은 누구인가 |
| 받아낼 결정 | 무엇을 승인받거나 결정받으려 하는가 |
| 성공 기준 | 무엇이 나오면 이 작업이 끝난 것인가. 검사 가능한 문장으로 |
| 지금 아는 것 | 이미 잰 값. 출처와 함께 |
| 모르는 것 | 확인해야 하는 것. 확인 방법 한 줄 |
| 안 할 것 | 이번에 손대지 않는 범위 |

"안 할 것"을 비워두지 않는다. 범위가 커지는 건 대개 여기가 비어서다.

## 세 축 중 무엇이 필요한가

같은 칸에 표시한다. 필요 없는 축은 부르지 않는다.

- **콘텐츠**: 설득 문서, 공지, 기획서가 나가야 하는가
- **분석**: 주장을 받칠 숫자를 새로 내야 하는가
- **디자인**: 화면이나 시각 산출물이 필요한가

세 축이 다 필요한 작업이 흔하다. 그럴 때 순서와 접합은 `weave`가 정한다.

## 어디에 두는가

작업 폴더에 `brief.md` 한 장. 세션이 바뀌어도 이 파일부터 읽고 시작한다.
작업 중 의도가 바뀌면 **파일을 고치고 무엇이 왜 바뀌었는지 한 줄 남긴다.**

## 하지 말 것

- 방침 없이 착수하기. 되돌리는 비용이 쓰는 비용보다 크다

- 결정권자를 "회사"나 "팀"으로 적기. 사람 이름이나 직책으로
