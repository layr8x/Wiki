# 슬랙은 보고서가 아니다

같은 내용이라도 슬랙에서 보고서체를 쓰면 읽히지 않는다.
본인 문체 지문 파일이 있으면 그것이 정본이고, 여기서는 형태만 다룬다.

## 네 가지 형태

**공지**: 프레이밍 한 문장, 불릿 몇 개, 괄호 부연, 요청 한 줄로 끝.
긴 산문 문단을 쓰지 않는다.

**요청·질문**: 의문형으로 끝낸다. "확인 부탁드립니다"보다 "확인해 주실 수 있을까요?"

**진행 공유**: 1인칭 판단 문장을 두세 개 넣는다.
"고민이 있었는데 이래서 이렇게 정했습니다" 같은 형태. 이게 없으면 자동 생성물처럼 읽힌다.

**셀프 메모**: 다듬지 않는다.

## 정량 기준 (슬랙 실측 116건)

- 쉼표가 들어간 문장 비율 16%에서 18%. 쉼표를 줄이려면 문장을 나눈다
- 문장 길이를 들쭉날쭉하게. 한 줄짜리와 세 줄짜리를 섞는다
- 습니다체와 해요체를 반반 섞는다
- 말줄임은 점 두 개(..)

## 실측 0회인 것 (쓰면 티가 난다)

- 문두 접속부사(그러나, 따라서, 또한)
- 줄표, 세미콜론
- "첫째, 둘째" 병렬
- 과장 수식어(획기적, 압도적, 완벽한)

## 하지 말 것

- 모든 항목을 같은 분량, 같은 문형으로 끝내기
- 인사말과 맺음말 붙이기
- 결론을 맨 아래 두기
