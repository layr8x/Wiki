# 숫자 꼬리표

숫자 하나가 무너지면 그 문서의 다른 숫자도 같이 안 믿긴다.
그래서 **모든 숫자에 잰 것인지 아닌지를 표시**한다.

## 세 가지 표시

| 표시 | 뜻 | 필요한 것 |
|---|---|---|
| 측정 | 실제로 센 값 | 조회한 곳과 기간. 예: 상담 DB(= 데이터 보관함), 2026-06-01부터 30일 |
| 추정 | 가정을 넣어 계산한 값 | 가정 한 줄과 범위. 예: 응대율 60% 가정 시 월 1,200건에서 1,500건 |
| 미측정 | 아직 확인 못 한 값 | 어떻게 확인할지 한 줄 |

미측정을 숨기지 않는다. 모르는 걸 모른다고 적은 문서가 더 강하다.

## 쓰는 법

- 표 안에서는 값 옆 괄호로. 예: 감소율 32% (측정)
- 문장 안에서는 문장 끝에. 예: 문의가 3분의 1로 줄었습니다 (측정, 상담 DB(= 데이터 보관함) 2026-06)
- 그림이나 대시보드에서는 범례 아래 한 줄로 모아서

## 추정은 보수적으로

범위로 적고, 낙관값을 대표값으로 쓰지 않는다.
"최대 40% 절감"보다 "20%에서 30% 절감, 가정은 아래"가 회의에서 안 무너진다.

## 인과를 주장하려면

"챗봇 때문에 문의가 줄었다"고 쓰려면 비교 대상이 있어야 한다.
같은 기간 아무것도 안 한 다른 채널이나, 도입 전 같은 시기.
비교 대상이 없으면 **"줄었다"까지만 쓰고 "때문에"는 쓰지 않는다.**

## 하지 말 것

- 출처 없는 숫자
- 소수점 늘려서 정밀해 보이게 하기. 32.7%는 32%보다 신뢰를 못 얻는다
- 분모를 안 밝히기. 비율은 분모가 바뀌면 뜻이 달라진다
- 사실이나 수치를 지어내기. 확인 못 했으면 미측정으로 남긴다
