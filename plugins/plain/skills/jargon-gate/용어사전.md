# 용어사전

산출물이나 답변에 아래 말이 나오면 그 자리에서 오른쪽 풀이를 괄호로 붙인다.
사전에 없는 낯선 말을 쓰게 되면 여기 먼저 추가한다.

## 개발 일반

| 용어 | 풀이 |
|---|---|
| 배포(deploy) | 만든 걸 실제 사이트에 올려 사람들이 쓰게 하는 것 |
| 빌드(build) | 사람이 쓴 코드를 컴퓨터가 실행할 형태로 묶는 작업 |
| 커밋(commit) | 변경 사항을 이력으로 저장하는 것. 저장 시점마다 이름표가 붙는다 |
| 브랜치(branch) | 원본을 건드리지 않고 따로 떼어 작업하는 사본 |
| PR(Pull Request) | 내 작업을 원본에 합쳐달라는 요청서 |
| 머지(merge) | 따로 작업한 걸 원본에 합치는 것 |
| 롤백(rollback) | 문제가 생겨 이전 상태로 되돌리는 것 |
| 리팩터링(refactoring) | 겉으로 하는 일은 그대로 두고 안쪽 구조만 정리하는 것 |
| 하드코딩 | 값을 코드에 직접 박아두는 것. 바꾸려면 코드를 고쳐야 한다 |
| 훅(hook) | 자동 잠금장치. 특정 시점마다 검사가 자동으로 돈다 |
| CI | 자동 검사 담당. 코드가 올라오면 규정 위반을 자동으로 훑는다 |
| 린트(lint) | 코드 맞춤법 검사 |
| 의존성(dependency) | 이 프로그램이 돌아가려면 같이 있어야 하는 남의 부품 |
| 환경변수 | 코드 밖에 따로 보관하는 설정값. 비밀번호 같은 걸 여기 둔다 |
| 캐시(cache) | 한 번 가져온 걸 저장해뒀다 다시 쓰는 것. 빠르지만 옛날 값이 남을 수 있다 |
| 로그(log) | 프로그램이 남긴 작업 일지 |
| API | 프로그램끼리 주고받는 창구. 정해진 형식으로 요청하면 정해진 형식으로 답한다 |
| 엔드포인트(endpoint) | 그 창구의 주소 한 개 |
| 리포지토리·저장소(repo) | 코드와 변경 이력을 모아둔 곳 |

## 데이터베이스

| 용어 | 풀이 |
|---|---|
| DB(데이터베이스) | 데이터를 넣어두는 보관함 |
| 테이블(table) | 보관함 안의 표 한 장 |
| 행(row)·레코드 | 표의 가로 한 줄. 데이터 하나 |
| 컬럼(column)·필드 | 표의 세로 한 칸. 항목 이름 |
| 스키마(schema) | 표의 설계도. 어떤 칸이 있고 어떤 형식인지 |
| 마이그레이션(migration) | 설계도를 바꾸고 기존 데이터를 새 설계에 맞추는 작업 |
| 쿼리(query) | 보관함에 던지는 질문. "6월 상담 몇 건" 같은 것 |
| SQL | 그 질문을 쓰는 언어 |
| 인덱스(index) | 책 뒤 색인. 찾는 속도를 올리지만 저장 공간을 더 쓴다 |
| FK(Foreign Key, 외래키) | 다른 표의 행을 가리키는 연결 규칙. 가리키는 대상이 먼저 있어야 한다 |
| RLS(Row Level Security) | 누가 어떤 행을 볼 수 있는지 정하는 규칙 |
| upsert | 있으면 고치고 없으면 새로 넣는 저장 방식 |
| 멱등(idempotent) | 같은 작업을 여러 번 해도 결과가 같은 성질. 중복 실행이 안전하다 |
| 백필(backfill) | 과거 기간의 빠진 데이터를 뒤늦게 채워 넣는 것 |
| 커서(cursor) | 어디까지 읽었는지 표시하는 책갈피 |
| RPC | 미리 만들어둔 조회 함수. 복잡한 질문을 이름 하나로 부른다 |

## 배포·운영

| 용어 | 풀이 |
|---|---|
| 서버 | 24시간 켜져 서비스를 돌리는 컴퓨터 |
| 클라우드 | 남의 서버를 빌려 쓰는 것 |
| 크론(cron) | 정해진 시각마다 자동 실행하는 예약 장치 |
| 엣지 함수(edge function) | 서버에 올려두고 부르면 도는 작은 프로그램 |
| 쿠키(cookie) | 로그인 상태를 유지하려고 브라우저가 들고 다니는 출입증 |
| 토큰(token) | 신분을 증명하는 임시 열쇠. 유효기간이 있다 |
| 401·403 | 401은 신분 확인 실패, 403은 신분은 맞는데 권한 없음 |
| 타임아웃 | 정해진 시간 안에 답이 안 와서 포기하는 것 |
| 헤드리스(headless) | 화면 없이 백그라운드로 브라우저를 돌리는 방식 |
| 웹훅(webhook) | 무슨 일이 생기면 상대가 먼저 알려주는 방식 |
| PII | 개인을 특정할 수 있는 정보. 이름, 전화번호, 주민번호 |
| 마스킹(masking) | 개인정보를 가려서 저장하는 것 |

## 데이터 분석·통계

| 용어 | 풀이 |
|---|---|
| 표본(sample) | 전체 중 일부만 뽑아 본 것 |
| 모수·전수 | 전체 다 |
| 중앙값(median) | 줄 세웠을 때 한가운데 값. 극단값에 안 흔들린다 |
| 평균 | 다 더해 나눈 값. 극단값 하나에 크게 흔들린다 |
| 분위수(p90 등) | 아래에서 90% 지점의 값. 상위권이 어느 정도인지 볼 때 쓴다 |
| 편차·변동(CV) | 값이 들쭉날쭉한 정도 |
| 상관 | 같이 움직이는 관계. 원인이라는 뜻은 아니다 |
| 인과 | 하나가 다른 하나를 실제로 일으킨 관계 |
| 유의수준·p값 | 우연히 이런 결과가 나올 확률. 낮을수록 우연이 아닐 가능성이 크다 |
| 이중차분(DID) | 아무것도 안 한 쪽과 비교해 변화분의 차이를 보는 방법 |
| 대조군 | 비교하려고 아무 처치도 안 한 쪽 |
| 코호트(cohort) | 같은 시기에 시작한 사람 묶음. 가입 월별로 묶는 식 |
| 리텐션(retention) | 처음 온 사람 중 나중에도 남아 있는 비율 |
| 퍼널(funnel) | 유입에서 전환까지 단계별로 몇 명이 남는지 보는 것 |
| 세그먼트 | 조건으로 나눈 사용자 묶음 |
| 베이스라인(baseline) | 비교 기준이 되는 평소 값 |
| 이상탐지 | 평소와 다른 값을 자동으로 찾아내는 것 |
| 정규화 | 단위나 크기가 다른 값을 비교 가능하게 맞추는 것 |
| 결측(missing) | 값이 비어 있는 것 |
| CRISP-DM | 분석을 여섯 단계로 나눈 표준 절차. 이해, 데이터 이해, 준비, 모델, 평가, 적용 |
| KPI 트리 | 최종 지표를 하위 지표로 쪼개 인과를 그린 그림 |
| North Star | 조직이 함께 보는 대표 지표 한 개 |
| RICE | 우선순위 점수. 도달, 효과, 확신, 노력 네 값으로 계산 |
| DMAIC | 개선을 다섯 단계로 나눈 절차. 정의, 측정, 분석, 개선, 관리 |
| 민감도 분석 | 가정을 바꿔 보며 결론이 얼마나 흔들리는지 확인하는 것 |

## AI·에이전트

| 용어 | 풀이 |
|---|---|
| 컨텍스트(context) | 한 번에 기억할 수 있는 분량. 서류 가방 용량 |
| 토큰(token, AI) | 글자를 세는 단위. 비용과 분량이 여기 비례한다 |
| 프롬프트 | AI에게 주는 지시문 |
| 스킬(skill) | 상황에 맞게 자동으로 펼쳐지는 지침서 파일 |
| 플러그인·부서 | 스킬 여러 개를 묶어 통째로 설치하는 단위 |
| 마켓플레이스 | 그 묶음을 등록해둔 목록 |
| frontmatter | 파일 맨 위 이름표. 언제 쓰는 문서인지 적는 칸 |
| MCP | AI가 외부 도구에 접속하는 규격 |
| 서브에이전트 | 일부 작업을 따로 떼어 맡기는 보조 AI |
| 할루시네이션 | AI가 없는 사실을 지어내는 것 |
| 레지스터(register) | 말투의 격. 보고서 말투와 카톡 말투의 차이 |
