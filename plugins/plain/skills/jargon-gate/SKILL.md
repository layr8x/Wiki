# 말 검사역: 용어 풀이

김명준님은 개발과 데이터 분석의 전문 지식이 없다.
용어를 안 풀면 **피드백을 줄 수 없고, 피드백이 없으면 작업이 틀린 채로 진행된다.**

## 규칙

| 어디 | 규칙 |
|---|---|
| 산출물(보고서·문서·대시보드) | 나올 때마다 매번 괄호로 풀이 |
| 채팅 답변 | 처음 나올 때 한 번 풀이 |
| 전 구성원 공유 문서 | 매번 풀이하고, **비유를 쓰지 않는다** |
| 김명준님 대상 채팅 | 비유를 써도 된다 |

풀이 형태는 괄호 안에 등호와 평이한 말이다. 예: RLS(= 누가 어떤 데이터를 볼 수 있는지 정하는 규칙)

## 검사 대상

`용어사전.md`에 등록된 말이 문서에 있는데 그 문장이나 바로 앞뒤에 풀이가 없으면 걸린다.
사전에 없는 낯선 말이 보이면 사전에 추가하고 풀이한다.

## 풀이하는 법

1. 한 문장으로. 두 문장 넘어가면 그것도 어렵다는 뜻이다
2. 명사가 아니라 **하는 일**로. "캐시(= 저장소)"보다 "캐시(= 한 번 가져온 걸 저장해뒀다 다시 쓰는 것)"
3. 영어 약어는 무엇의 줄임인지까지. 예: FK(= Foreign Key, 다른 표의 행을 가리키는 연결 규칙)
4. 김명준님이 아는 영역의 말로. 디자인, 화면, 사용자 흐름은 풀이가 필요 없다

## 하지 말 것

- 풀이 없이 쓰고 "나중에 설명드리겠습니다"로 넘기기
- 풀이를 각주나 부록으로 빼기. 그 자리에 있어야 읽힌다
- 풀이한다면서 다른 전문용어를 쓰기
- 전 구성원 문서에 비유 쓰기. 천장, 집, 무게중심 같은 말 대신 상한, 한계, 우선순위로
