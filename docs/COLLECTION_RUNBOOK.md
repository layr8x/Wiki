# 카카오/잔디 수집 장애 대응 안내 (운영 런북)

한 줄 요약: 수집이 멈추면 슬랙으로 알림이 옵니다. 대부분은 "담당자 기기에서 다시 로그인" 한 번으로 해결됩니다.

이 문서는 개발 지식이 없어도 따라 할 수 있게 쓴 대응 안내입니다. 증상별로 "무엇을 하면 되는지"만 담았습니다.

## 0. 먼저 알아둘 것

- 카카오는 여전히 담당자 기기(2026-08-13 부터 맥북 에어)가 6시간마다 로그인 쿠키를 뽑아 서버로 보내야 합니다.
- **잔디는 2026-07-09부터 서버가 스스로 열쇠를 갱신합니다(담당자 기기 없이도 안 끊김).** 잔디 열쇠(access token)가 4시간 이하로 남으면 서버(jandi-refresh)가 자동으로 새 열쇠를 받아옵니다. 단, 최초 1회는 사람이 로그인해 "갱신용 열쇠(refresh_token)"를 심어둬야 하고, 그 갱신용 열쇠 자체가 만료되면(드문 경우) 다시 사람 로그인이 필요합니다.
- 열쇠가 만료되면 수집이 멈추고, 서버 감시(워치독)가 **슬랙으로 알림**을 보냅니다.
- 데이터는 "이어받기(커서)" 방식이라, 열쇠만 다시 넣으면 **멈춘 동안 밀린 것도 자동으로 따라잡습니다.** 영구 손실은 아닙니다(단, 아주 오래 멈추면 일부 구멍 가능성은 있음).

## 1. 증상별 대응표

## 2. 열쇠 다시 넣기 (담당자 기기에서)

수집 기기는 2026-08-13 부터 맥북 에어입니다. **노트북이라 뚜껑을 닫으면 잠들고, 자는 동안 수집이 멈춥니다.** 책상에 두고 상시 수집하려면 전원을 연결하고 뚜껑을 열어 둔 채 `sudo pmset -c sleep 0 disablesleep 1` 로 시스템 절전을 꺼 두세요.

### 2-1. 카카오 쿠키 재발급

1. 담당자 기기에서 카카오 비즈니스 채팅에 로그인된 상태를 확인합니다.
2. 터미널에서 `npm run kakao:refresh-cookie` 를 실행합니다(전용 크롬 프로필로 쿠키를 뽑아 서버로 보냄).
3. 몇 분 뒤 슬랙에 "정상으로 돌아왔어요" 가 오면 완료입니다.

### 2-2. 잔디 재로그인 (가장 흔한 케이스, 토큰 수명 약 12시간)

1. 담당자 기기의 **잔디 전용 크롬 프로필**로 잔디에 로그인합니다(세션이 풀려 있으면 다시 로그인).
2. 터미널에서 `npm run jandi:refresh-token` 을 실행합니다.
   - 세션이 풀려 자동으로 안 되면 `JANDI_HEADLESS=false npm run jandi:refresh-token` 으로 창을 띄워 직접 로그인합니다.
3. 스크립트는 **새로 받은 토큰이 진짜 유효한(미래 만료) 값일 때만 저장**합니다. 만료된 값은 저장을 거부하니, 거부 메시지가 나오면 로그인이 덜 된 것입니다. 다시 로그인 후 재실행하세요.
4. 몇 분 뒤 슬랙에 "정상으로 돌아왔어요" 가 오면 완료입니다.

## 3. 기기가 꺼졌다 켜진 경우

1. 자동 실행 등록(launchd)이 살아 있는지 확인: 터미널에서 `launchctl list | grep amswiki` 에 항목들이 보이면 정상입니다.
2. 잔디/카카오 전용 크롬 프로필의 로그인이 유지되는지 확인합니다(재부팅 후 풀렸을 수 있음). 풀렸으면 2-1, 2-2 를 각각 1회 실행합니다.

## 3-1. ★ 수집 기기를 바꾼 경우 (가장 놓치기 쉬운 것)

**증상: 알림도 오류도 없는데 수집만 0건.** 슬랙에는 "지연" 알림이 오지만 로그인은 멀쩡합니다.

**원인: 자동 실행 예약이 새 기기에 없습니다.** 소스코드 폴더는 iCloud 에 있어 새 기기에서도 바로 보이지만,
"5분마다 실행해라"는 예약은 `~/Library/LaunchAgents` 에 저장되고 그 폴더는 **iCloud 로 동기화되지 않습니다.**
2026-08-13 맥 스튜디오 → 맥북 에어 이전 때 이걸 놓쳐 5시간 넘게 멈췄습니다.

**할 일 — 새 기기에서 아래 한 줄:**

```bash
cd ~/Library/Mobile\ Documents/com~apple~CloudDocs/MacStudio-MJ/local && bash scripts/install-launchd.sh
```

이 스크립트가 node 실제 경로와 저장소 위치를 이 기기 값으로 맞춰 예약을 걸어 줍니다.
(직접 복사하면 안 되는 이유: 예약 파일에 node 경로가 `/usr/local/bin/node` 로 박혀 있는데
애플 실리콘 맥은 `/opt/homebrew/bin/node` 라 **조용히 실패**합니다.)

**노트북이면 추가로:** 뚜껑을 닫는 동안 수집이 멈춥니다. 전원을 연결하고 뚜껑을 열어 둔 채
`sudo pmset -c sleep 0 disablesleep 1` 로 시스템 절전을 꺼 두세요.

## 4. 안전망 요약 (자동으로 도는 것들)

- 카카오 수집: 5분마다. 감시: 10분마다.
- 잔디 수집: 5분마다. 감시: 10분마다(토큰 만료 사전 경고 포함).
- **잔디 열쇠 서버 자동갱신(jandi-refresh): 30분마다 확인, 4시간 이하로 남으면 자동 갱신.** 담당자 기기 재로그인 없이도 잔디가 계속 돕니다. 단, 이 방식은 잔디가 공식 지원하는 자동화 방법이 아니라 웹앱 내부 동작을 그대로 재현한 것이라, 잔디 쪽 정책 변경 시 갑자기 안 될 수 있습니다(그 경우도 워치독이 잡아 알림).
- 카카오 분석(분류/일일요약): 15분/매일. 분석 정지도 이제 슬랙으로 알립니다.
- 모든 알림은 슬랙 한 채널로 갑니다. (슬랙이 죽으면 알림이 안 올 수 있어, 2차 알림 채널 이중화는 개선 예정입니다.)
