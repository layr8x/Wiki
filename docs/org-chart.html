02

콘텐츠persuade

스킬 4

보고서·기획서·슬랙 공지의 뼈대, 숫자 꼬리표, 예상 반론. 결정을 받아내는 문서를 만든다.

  1. number-tags

    문서나 대시보드에 숫자, 지표, 비율, 금액을 넣을 때 출처와 신뢰도를 표시한다.

  2. objection-first

    승인이나 예산, 인력, 일정 변경을 요청하는 문서를 쓸 때 예상 반론을 미리 적어 답한다.

  3. report-blueprint

    보고서, 기획서, 제안서, 분석 결과 문서의 뼈대를 잡는다.

  4. slack-notice

    슬랙 공지, 요청, 질문, 사내 메시지 초안을 쓸 때 사용한다.
