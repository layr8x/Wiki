# 바이브 코딩 실전 가이드 ③ Supabase

> **바이브 코딩 실전 가이드 시리즈**: ① 시작하기 · ② GitHub · **③ Supabase (이 문서)** · ④ Vercel

> 📌 **한 줄 요약**
> Supabase(슈파베이스)는 **"데이터 보관함 + 로그인 관리사무소 + 자동화 직원"** 입니다.
> 내 서비스에 **데이터 저장·로그인·자동작업**이 필요해지면 본인 프로젝트를 하나 만들어 붙입니다.
> 표를 만들고, 데이터를 조회·분석하고, 정해진 시각에 자동으로 도는 작업까지 여기서 다룹니다.

> ℹ️ **언제 쓰나**: 단순한 웹페이지엔 필요 없습니다. **데이터를 저장하거나(예: 메모·신청·상담 기록), 로그인을 붙이거나, 자동으로 반복 작업을 돌릴 때** 씁니다. (사내 카카오 상담 수집 서비스가 바로 이 Supabase 위에서 자동으로 돌아가는 실제 사례입니다.)

---

## 1. Supabase가 뭔가요? (비유)

Supabase는 **거대한 엑셀 창고 + 출입증 발급소 + 24시간 자동화 직원** 세 가지를 합친 것입니다.

- **데이터 보관** (창고): 내용을 "표(테이블)" 형태로 보관. 엑셀 시트가 수십만 줄까지 커진 것.
- **로그인 관리** (관리사무소): 내 서비스에 누가 로그인할 수 있는지 관리.
- **자동화 직원**: "5분마다 무언가 수집", "매일 아침 요약 발송" 같은 일을 **정해진 시각에 자동 실행**.

엔진은 은행권도 쓰는 **PostgreSQL**이라는 튼튼한 데이터베이스입니다. 개인은 **무료 플랜**으로 충분히 연습할 수 있습니다.

---

## 2. 본인 것 만들기 (처음 한 번만)

### 1단계. 가입
**https://supabase.com/dashboard 에서 GitHub 계정으로 로그인**이 가장 간단합니다.

### 2단계. 프로젝트 만들기
1. **`New project`** 클릭
2. **Name**(프로젝트 이름), **Database Password**(데이터베이스 비밀번호) 설정
   - ⚠️ 이 비밀번호는 **안전한 곳에 따로 저장**하세요. (비밀번호 관리앱 등)
3. **Region**(지역)은 **`Northeast Asia (Seoul)`** 처럼 가까운 곳 선택 (빠릅니다)
4. **`Create new project`** → 1~2분 준비되면 완료

이제 나만의 데이터 창고가 생겼습니다.

### 3단계. 내 서비스와 연결하는 값 확인 (나중에 씀)
- **Settings → API** 에 **프로젝트 URL** 과 **키(API Key)** 가 있습니다.
- 나중에 AI에게 "이 Supabase에 연결해줘"라고 할 때 씁니다. **키는 외부에 노출 금지** (아래 6번 참고).

## 3. 화면 둘러보기 (왼쪽 메뉴 지도)

| 메뉴 | 우리말 | 여기서 뭘 하나 |
|---|---|---|
| **Table Editor** | 표 편집기 | 표(데이터)를 **엑셀처럼 만들고 조회** |
| **SQL Editor** | 명령 편집기 | 원하는 조건으로 조회·분석 (조회는 안전) |
| **Authentication** | 로그인 관리 | 내 서비스 로그인 사용자 관리 |
| **Edge Functions** | 자동 기능 | 자동으로 도는 작은 프로그램 |
| **Database → Cron Jobs** | 예약 작업 | "몇 분마다 실행" 예약 목록·성공 여부 |
| **Logs / Reports** | 기록 / 통계 | 오류 기록, 사용량 그래프 |

> 📷 (컨플루언스에 Table Editor 화면 캡처를 넣으면 이해가 빠릅니다.)

## 4. 실전: 직접 해보기

### 실전 A. 첫 표(테이블) 만들기
가장 쉬운 건 AI에게 시키는 것입니다. 예: **"메모를 저장할 표를 Supabase에 만들어줘. 제목과 내용, 작성시간 칸이 필요해."**
- 직접 만들려면: **`Table Editor` → `New table`** → 이름과 칸(Column)들을 추가 → 저장.

### 실전 B. 데이터를 표로 조회
1. **`Table Editor`** → 볼 표 선택
2. 엑셀처럼 내용이 뜹니다. 위쪽 **`Filter`(거르기)** 로 원하는 조건만 보기
3. 상단/하단에 **총 건수(row 수)** 표시

### 실전 C. 원하는 질문으로 분석하기 (조회 명령)
"이번 달 등록이 몇 건이지?" 같은 걸 직접 뽑을 수 있습니다. **조회(SELECT)는 데이터를 바꾸지 않아 안전**합니다.
1. **`SQL Editor` → `New query`**
2. AI에게 **"이 표에서 이번 달 건수를 세는 조회 쿼리 만들어줘"** 부탁 → 받은 명령 붙여넣기
3. **`Run`(실행)** → 결과가 표로 뜸

> 💡 **`select`(조회)로 시작하는 명령만** 마음껏 실행하세요. `update`·`delete`·`drop`은 데이터를 바꾸거나 지우므로, 실행 전 AI에게 "이거 데이터 바꾸는 명령이야?" 확인부터.

### 실전 D. 자동작업 이해하고 운영하기
"매 시각 무언가 자동으로" 가 필요하면 자동작업(Edge Function + Cron)을 씁니다.
- AI에게 **"매일 아침 9시에 어제 등록 건수를 요약해 저장하는 자동작업 만들어줘"** 처럼 시키면 됩니다.
- **`Edge Functions`** 나 **`Database → Cron Jobs`** 에서 그 작업이 잘 도는지(성공/실패) 확인합니다.

> 참고: 사내 카카오 상담 수집도 이렇게 "5분마다 수집 → 분류 → 이상하면 알림 → 매일 요약" 자동작업으로 돌아갑니다. 여러분도 본인 아이디어에 맞는 자동작업을 만들 수 있습니다.

## 5. 되돌리기 어려운 것 (주의)

| 주의 대상 | 왜 |
|---|---|
| **표의 값 수정·행 삭제(Delete row)** | 저장된 데이터가 바뀌거나 사라짐. 조회는 마음껏, 수정은 신중 |
| **`SQL Editor`에서 `delete`·`drop`·`truncate` 실행** | 한 줄로 표 전체가 날아갈 수 있음. 실행 전 AI에게 확인 |
| **키(API Key)·DB 비밀번호를 외부로 전송/코드에 그대로 올림** | 새면 남이 내 데이터에 접근. AI에게 "환경변수로 빼줘"라고 시키기 |
| **프로젝트 삭제** | 데이터 전체가 사라짐 |

> 조회(SELECT)와 자동작업 점검은 아무리 해도 안전합니다. 겁낼 부분과 조심할 부분을 구분하세요.

## 6. 용어 사전

| 용어 | 쉬운 뜻 |
|---|---|
| 데이터베이스 (DB) | 데이터를 담는 거대한 창고. 우리는 PostgreSQL |
| 테이블 (Table) | 창고 안의 "표 한 장" (엑셀 시트) |
| 행 (Row) / 열 (Column) | 표의 가로 한 줄(기록 하나) / 세로 항목(예: 제목, 날짜) |
| SQL | 데이터에게 질문·명령하는 언어. `select`(조회)가 가장 안전 |
| Edge Function | 필요할 때 도는 작은 자동 프로그램 |
| cron (크론) | "5분마다", "매일 9시"처럼 자동 실행하는 예약 |
| RLS (행 수준 보안) | "누가 어떤 줄을 볼 수 있는지" 정하는 접근 규칙 |
| API Key (키) | 프로그램이 창고에 접근하는 비밀 열쇠. **외부 유출 절대 금지** |

---

## 7. 연결 원리 (AI와 함께 실제로 어떻게 도나)

1. 내 서비스(사이트·자동작업)는 **"프로젝트 URL + 키(Key)"** 로 Supabase에 접속합니다.
2. 키는 두 종류: 화면에 노출돼도 비교적 안전한 **공개용 키(anon key)** 와, 서버 뒤에서만 쓰는 **관리자 키(service key, 절대 유출 금지)**.
3. 이 값들은 코드에 직접 안 적고 **환경변수(몰래 넣어두는 설정값)** 로 보관합니다. AI에게 맡기면 알아서 이렇게 처리해 줍니다.
4. 자동작업은 **cron 예약**으로 정해진 시각에 스스로 깨어나 실행됩니다.

## 8. 문제가 생기면

| 증상 | 이렇게 하세요 |
|---|---|
| 프로젝트가 안 열림 | 준비(1~2분) 중일 수 있음. 잠시 후 새로고침 |
| 조회 명령이 빨간 오류 | 명령 오타일 뿐 데이터엔 영향 없음. 오류 메시지를 AI에게 그대로 전달해 고쳐 받기 |
| 표를 잘못 수정한 것 같음 | **더 누르지 말고** 화면 캡처 후 AI에게 상황 설명 |
| 키·DB 비밀번호를 실수로 외부에 보냄 | Settings에서 재발급(Reset) 필요. AI에게 도움 요청 |

> 확신이 안 서면 **조회(SELECT)만 하고, 바꾸는 명령은 AI에게 확인받은 뒤** 실행하세요.
