# 분기 운영 인사이트 보고 - 전화·카카오·웹 3채널 한눈에

> **3줄 요약**
> 1. 학원 문의는 **채널마다 성격이 완전히 다르다** - 전화(6개월 42만 건)는 출결·입반 같은 *운영 처리성* 문의가, 카카오·앱 같은 디지털 채널은 *계정·로그인*(앱에 못 들어감)이 지배한다.
> 2. 디지털 채널 최대 수요는 **계정·로그인·앱(카카오 36.2%, 마이클래스·라이브는 각 약 56%)** 인데, 이건 *로그인 전*에 터지는 문의라 인앱 챗봇이 닿지 못한다(상세 = 산출물 2).
> 3. 따라서 자동화는 한 군데가 아니라 **"전화 운영성 → 인앱 챗봇 / 계정·로그인 → 로그인 화면·카카오"** 로 채널별로 따로 배치해야 한다.

> **이 보고의 성격**: 경영·분기용 1장 인사이트. 모든 수치는 실측(추정은 '추정'으로 명시). 챗봇은 아직 **미배포** 상태라 어떤 추세도 챗봇 효과로 귀속하지 않는다(5장).

## 2. 채널별 - 무엇을 묻나

### 2-1. 전화 (AMS 상담, 6개월 424,200건 · 대치단과)

가장 많이 들어오는 건 전부 **"내 정보 확인 / 운영 처리"** 성격이다.

| 대분류 | 비중 |
|---|---:|
| **출결 관리** | **30.7%** |
| **입반 상담** | **22.0%** |
| LIVE | 14.9% |
| 퇴원 상담 | 9.0% |
| 정산·수납 | 8.2% |
| 대기자 관리 | 6.3% |

- **출결 + 입반 = 52.7%.** 상위가 모두 반복 조회·신고성.
- 채널: 전화 **96.7%** / 대상: 학부모 **92.1%**.
- → 운영 인력이 전화에 묶여 있다. 전화를 줄이는 것이 곧 운영 효율.

### 2-2. 카카오 비즈채팅 (라이브 수집 85,936메시지 / 7,291대화 · 3채널)

전화와 **정반대로** 계정·로그인이 1위.

| 카테고리 | 비중 |
|---|---:|
| **계정·로그인·앱** | **36.2%** |
| 기타 | 28.0% |
| 환불 | 8.0% |
| 라이브 | 5.9% |
| 교재·배송 | 5.2% |
| 입반·등록 | 4.1% |
| 미납·결제 | 4.1% |

- 발신자: 재원생·학부모(user) 46.2% ↔ 상담원(manager) 29.3% → **진짜 양방향 상담**(단순 알림 아님). 자동 분류 적용 **98.7%**.
- 이 채널엔 학부모뿐 아니라 **재원생도 직접 문의**(앱을 직접 쓰는 학생 비중 큼).

## 3. 채널 교차 구조 - "전화 = 운영, 디지털 = 계정·로그인"

세 채널을 **같은 분류 잣대**로 겹쳐 보면 구조가 또렷하다.

| | **전화** (운영 처리) | **카카오·앱** (디지털 진입) |
|---|---|---|
| 1위 문의 | 출결 30.7% | 계정·로그인 36.2% |
| 성격 | 내 정보 확인·신고·반복 조회 | "앱에 못 들어감" |
| 누가 | 학부모 92.1% | 재원생·학부모 혼재 |
| 계정·로그인 비중 | **0.2%** | 마이클래스 56.5% · 라이브 56.2% |

**채널별 색깔이 다르다 (서비스별 Top)**

| 채널 | 1위 | 2위 | 3위 |
|---|---|---|---|
| **라이브** | 계정·로그인 56.2% | 라이브 수강 14.8% | 입반·등록 |
| **마이클래스** | 계정·로그인 56.5% | 입반·등록 6.0% | 출결·보강 5.6% |
| **시대인재C** | 환불 14.4% | 계정·로그인 13.6% | 교재·배송 9.7% |

- **디지털 서비스(마이클래스·라이브)**: "앱에 못 들어감"(계정·로그인)이 압도적.
- **시대인재C(통합회원·물류 중심)**: 환불·교재·배송 등 정산·물류성.
- → 같은 카카오라도 채널마다 다른 FAQ·자동응답이 필요하다. 분리 수집했기에 보이는 구조다.

> ★ 가장 중요한 교차 통찰: 디지털 최대 수요인 **계정·로그인은 "로그인 전"에 발생**한다. 그런데 인앱 챗봇·도움말은 **"로그인 후" 화면에 산다.** → 정작 그 사용자에겐 챗봇이 닿지 않는다. 이 함정과 배치 제안은 **산출물 2(계정·로그인 도움 배치 제안)** 에서 다룬다.

## 4. 운영 시사점 - 어디에 무엇을 배치하나

| 수요(어디서 터지나) | 자동화·배치 위치 | 근거 |
|---|---|---|
| **출결·입반·결제** (전화 운영성) | **인앱 챗봇** (재원생용, 로그인 후 화면) | 전화 상위 = 출결30.7·입반22·정산8.2 → "내 정보 확인"으로 끝나는 게 많음 |
| **계정·로그인·앱** (디지털 진입) | **로그인 화면 셀프 안내 + 카카오 채널 자동응답** | 마이클래스·라이브 약 56% / 전화 0.2% → *로그인 전* 수요라 인앱 챗봇 사각지대 |
| **환불·교재·배송** (시대인재C) | **C 채널 전용 FAQ·응대 스크립트** | C 1·3위가 환불·교재 |
| 모바일 전반 | 모든 자동화 UX = **모바일 우선** | 웹 모바일 79.4% |

**우선순위 한 줄** - ① 인앱 챗봇은 전화 출결·보강·입반·결제에 정조준(이미 기획 진행). ② 그와 **별개로** 계정·로그인은 로그인 화면·카카오로 빼야 한다(이번 분기 신규 제안 = 산출물 2).

## 5. 한계 · 정직성

- **챗봇 미배포** → 현재 상담량 추세를 **챗봇 효과로 귀속 금지**. 본 보고는 "지금 무엇이 어디서 터지나"의 현황 진단이다.
- **분모가 채널마다 다름**: 전화=건(424,200), 카카오=대화/메시지, 웹=세션/사용자 → 비중은 **채널 내 구성**으로만 비교(채널 간 절대 건수 직접 비교 금지).
- **AMS는 대치단과 단일 지점**(전지점 아님). 6월은 부분 집계(AMS 6/17까지).
- **카카오**: `기타` 분류 비중 높음(특히 시대인재C 45.5%) · 감정분석(sentiment) 미적재 · 학생/학부모 세부 구분 필드 없음.
- **GA4**: 일부 기간(2월 중순~3월 중순) export 누락 → 월별 추세는 6월 중심으로만 사용.
