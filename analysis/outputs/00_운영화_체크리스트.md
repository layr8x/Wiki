## D. 주의·결정 필요

- **왜 함수를 못 늘리나**: 이 저장소는 이미 서버리스 함수 12개(Vercel Hobby 한도)를 꽉 쓰고 있습니다(과거에도 이 한도로 통합한 이력). 그래서 대시보드를 **함수 없이** 빌드타임 JSON으로 구현했습니다.
- **⑧ Slack 자동 푸시**(상태 변할 때 알림)는 Vercel 함수로 못 올립니다(한도). → **Supabase pg_cron/Edge Function**(카카오 수집과 동일 인프라, Vercel 한도 무관)으로 별도 추가 예정. 현재는 **대시보드가 🔴 중단을 시각으로 표시**합니다.
- **실시간 대시보드**가 필요하면: ⓐ Vercel 함수 한도를 Pro로 올리고 라이브 API 부활, 또는 ⓑ 빌드를 더 자주(예약 재배포) 돌리기.
- `cs-stats.json`은 **비PII 집계만**(상담 원문 없음). 사내 위키 내부용.
- ② 자동응답 게시는 주제별 **시차 배포** 권장(효과 귀속 혼선 방지, §02-4).
