  3. "특강(여름·서바이벌 시즌) 라이브 열리나요 / 추가모집 하나요"
  4. "강좌목록에 보이질 않는데 신청 못 하는 건가요"
  5. "현강 마감 강좌를 옆 교실에서 라이브로 듣는 반, 어떻게 신청하나요"

- **해결 방안**
  - **카카오 자동응답 + FAQ**: "수강신청 일정·방법" 고정 안내(시즌 오픈일·신청 경로 캡처). 신청 시즌 직전 채널 상단 고정.
  - **챗봇(2차)**: "신청 가능한 강좌/특강 조회" + 신청 페이지 딥링크. 1차는 조회·안내, 2차에 신청 연결.

### ② 계정·로그인·앱 — 21건 (13.0%)

- **대표 질문(마스킹 요약)**
  1. "학생/학부모 전화번호가 바뀌어 등록됨 → 교체/삭제해 주세요"
  2. "본인 번호 인증하니 '이미 등록된 번호'라고 떠서 등록이 안 됩니다"
  3. "학원 정보 연동했는데 **수강 강좌가 안 떠요**(과제·영상 확인 불가)"
  4. "로그인/비밀번호 변경이 안 됨(없는 회원이라고 뜸)"
  5. "이름·성별·생년월일이 잘못 등록 → 정정 요청"
- **왜 많은가(근본원인 · 5 Whys 요약)** — ①앱에서 학생 정보가 안 보임 → ②학생 번호가 미등록/오등록 → ③한 번호가 다른 계정에 이미 묶여 "이미 등록된 번호" 에러 → ④학생·학부모가 각자 가입해 번호가 엇갈림 → ⑤**가입·접수 시 학생/학부모 번호를 한 계정에 정확히 매칭하도록 강제하지 않음**(셀프 수정도 인증 벽에 막힘).
- **★ 교차 통증 — "학생↔학부모 번호" 문제**: 번호 등록·교체·삭제 언급이 **26개 대화**(텍스트 대화의 약 17%). 카테고리(계정·통합회원)를 가로지르는 **단일 최대 통증**. "결제·수강 문자가 부모 번호로만 가서 불편" → 번호를 바꾸려는데 앱에서 막힘 → 채널로 옴.
- **해결 방안**
  - **제품/프로세스 수정(1순위 레버)**: 가입·접수 화면에서 **학생/학부모 번호 매칭을 명시·강제**. "이미 등록된 번호" 에러에 **셀프 해결 경로**(어느 계정에 묶였는지 안내) 제공.
  - **셀프 수정 + FAQ**: "번호 변경/삭제 방법" 가이드. 인증 막힐 때의 대안 안내.
  - **연동 실패('강좌 안 떠요')**: 연동 후 강좌 노출까지의 조건·대기시간을 앱 내 안내 + 재연동 버튼.
  - **배치 주의**: 로그인/연동 문제는 *로그인 전·연동 전*에 발생 → **인앱 챗봇이 닿지 않음**. 도움말은 **로그인 화면·카카오 채널**에 둬야 효과(기존 통합 분석과 동일 결론).

  1. "대기 번호가 111번인데 단순 번호인지, 앞에 110명인지 모르겠어요"
  2. "앱 대기접수 현황에 **안 떠요**(유선상으론 됐다는데)"
  3. "대기 등록이 임의로 사라졌어요 / 실수로 취소했는데 복구 가능한가요"
  4. "500번 넘는 대기번호는 정확히 몇 번인지 알 수 없나요"
- **왜 많은가** — 대기번호의 **의미(내 앞 인원)·정확한 순번이 앱에 불명확**하고, 유선 접수와 앱 표시가 **불일치**해 "제대로 걸렸나"를 확인. 대기 = "1년 농사" 인식이라 불안 강함.
- **해결 방안**
  - **챗봇 셀프조회(1차)**: "내 대기 현황 + 순번 + 의미 설명" 조회. 유선↔앱 데이터 동기화 표시.
  - **제품 수정**: 대기번호 옆 "내 앞 대기 N명" 명시, 큰 번호도 실수치 노출.
  - **배치**: 챗봇 전반/대기 조회 + 앱 대기현황 화면.

  - **FAQ**: "계정 2개일 때 통합 절차" 표준 안내(양식·소요시간).
  - **배치**: 카카오 채널 FAQ + 가입 화면. **챗봇으로는 발생을 못 막음** → 접수 단계 수정이 핵심.

- **대표 질문**: "결제 문자(링크)는 언제 오나요 / 학생 앱에선 결제가 안 되고 조회만 돼요", "결석으로 납부일이 들쭉날쭉인데 몇 주치 남았나요", "수업/교재 환불 가능한가요·교재 회수는?", "결제 취소 후 2개월로 재결제 원해요".
- **근본원인** — 결제 **문자·납부 상태가 안 보여** "냈는지/언제 오는지"를 사람에게 확인. 환불은 **규정·진행 단계 안내 부재**로 라이프사이클마다 문의.
- **해결 방안**
  - **챗봇 셀프조회(1차)**: 납부 현황(필요/대기)·결제 내역 조회 → 기존 결제화면 연결.
  - **FAQ + 자동안내**: 환불 규정·절차·교재 회수 〔학원 정책 확인〕. 환불 **접수→처리 단계 자동 알림**.
  - **배치**: 챗봇 납부·결제 메뉴 + 환불 FAQ.

### ⑧ 퇴원·취소 12건 / ⑨ 시간표·수업 6건 / ⑩ 교재·배송 5건 / ⑪ 라이브 수강 2건 (요약)

- **퇴원·취소**: 신청·구매 취소, 드랍, 탈퇴. → 일부는 셀프 취소 가능하게(2차), 환불 동반 건은 상담 유지.
- **시간표·수업**: 전반(시간 변경)·현강↔라이브 전환·종강/회차 조회. → 챗봇 시간표 조회 + 전반 안내.
- **교재·배송**: 배송 지연·배송지 변경·교재 단독 구매/회수. → FAQ + 배송 조회.
- **라이브 수강**: 영상 끊김·스타플레이어 오류. 건수는 적지만 **장애성**이라 즉시 기술 대응 필요. → 앱/플레이어 안정화 + 트러블슈팅 FAQ.

## 4. 핵심 인사이트 (의사결정용)

1. **이 채널의 본질은 "앱이 내 정보를 못 알아본다"** — 입반·대기·출결을 신청·확인하려는데 번호·계정·연동이 꼬여 막힌다. 표면 카테고리는 흩어져 보여도, **번호·계정 꼬임(통합회원+계정 = 22%, 번호 문제만 26개 대화)** 이 여러 카테고리를 가로지르는 **단일 최대 통증**이다.

2. **챗봇으로 '바로' 줄일 수 있는 건 조회형 34%** — 대기현황·출결/보강·시간표·납부조회는 "내 정보 보여주기"라 1차 셀프조회로 즉시 흡수 후보. 기획서 v6의 4메뉴(출결·보강 / 납부·결제 / 수업·시간표 / 전반)와 정확히 맞물린다. **1순위 = 출결·보강 + 대기/전반**(이 채널 상위가 전부 여기).

3. **가장 아픈 22%(계정·번호·통합)는 챗봇이 못 막는다** — 이 수요는 *로그인 전·접수 단계*에서 생기는데, 인앱 챗봇은 *로그인된 앱 안*에 산다(기존 통합 분석의 '함정'과 동일). → **레버는 가입·접수 화면 수정**(번호 매칭 강제·중복 차단·셀프 통합/탈퇴) + 도움말을 **로그인 화면·카카오 채널**에 배치.

4. **시스템 자동문구·재질문이 메시지의 절반** — 시스템 41.6% + 고객의 양식 재입력. 양식 안내·"언제 신청하나요"류는 **카카오 자동응답·고정 FAQ**로 사람 손을 거치지 않게 줄일 수 있다(상담원 부하 직접 절감).

5. **시즌이 부하를 만든다** — 6월 말 수강신청·여름특강 시즌에 대화가 급증(쌍봉). 같은 문의가 시즌마다 반복되므로, **시즌 직전 FAQ·자동응답·챗봇 조회를 준비**해 두면 부하를 선제 흡수할 수 있다.

## 5. 한계·정직성

- **단일 채널·1개월**: 마이클래스 채널 6월 전수일 뿐, **전화 상담·다른 카카오 채널(라이브·시대인재C)은 미포함**. 이 채널은 '앱 기술지원' 성격이라 **계정·앱 문제가 과대 대표**될 수 있다(전화 채널은 출결·입반이 더 큼 — 기존 통합 분석 참조).
- **표본이 작다(162 대화)**: 비중 1~2%p 차이는 유의미하지 않다. 상위 3~4개 카테고리의 **순위·구조 파악용**으로 보는 게 맞다.
- **분류는 키워드 규칙 + 원문 검수**: 정확도 한계가 있어 **추세·비중 비교용으로 충분, 절대수치는 ±**. 한 대화에 의도가 여러 개일 때 **가장 지배적인 1개**로 판정(예: 번호변경+수강신청 → 더 강한 쪽).
- **미분류(기타) 10.5%**: 그 중 9건은 고객 텍스트가 없는 대화(사진/시스템만). 깎을 모수(흡수율)의 분모에서 이 노이즈는 제외하고 읽어야 한다.
- **챗봇 미배포 → 인과 귀속 금지**: 위 흡수율(34%·22%)은 **잠재 추정**이지 측정된 감소가 아니다. 배포 후 **선행지표(챗봇 자가해결률·셀프조회 사용)→결과지표(채널 문의·상담원 응대 건수 감소)** 사슬로 별도 측정 필요.
- **학생/학부모 구분 필드 없음**: 발신자에 학생·학부모 구분이 없어 본문 정황으로만 추정.
- **학원 정책 구체값**(환불 규정·지점 전화번호·VOD 시청기한 등)은 데이터에 없어 **〔학원 정책 확인〕** 으로 비워 둠.
