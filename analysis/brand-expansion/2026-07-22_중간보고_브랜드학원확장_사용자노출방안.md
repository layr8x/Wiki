## 교정 메모 (원문 초안 대비)

- 오타 교정: "프론트 제공 방은을" -> "방안을".
- 어휘 교정(휴머나이저 패턴): "이를 통해" / "~함으로써" / "~하도록 하여 확보합니다" / "경험하게 됩니다" / "~하는 것입니다" / 문두 "다만" 제거. 쉼표 문장 비율 75% -> 13%.
- 구조 교정(문체지문 v2 공지 모드): 프레이밍 1문장("공유드립니다!") + 판단 공개 1문장("고민이 있었는데 ~ 방향으로 잡았습니다") + 요청 1줄 마무리. 섹션 분량은 중요도대로 불균형(3번 통합회원이 가장 길고 1번은 한 문장).
- 내용 보존: 4개 섹션 구성, 이미지 캡션 문구, URL 2종, "검토 중" 상태 표기는 원문 그대로 유지. 새로 넣은 사실 없음(3번의 "같은 화면, 학원명만 교체"는 첨부 이미지 2장에서 확인되는 내용).
- 측정: tools/writing/ko_ai_score.py --mj 기준 위험 0 / 주의 1(문단 길이 변동 0.41, 주의선 0.45). 문장 23개, 쉼표 문장 13%, 문장 길이 CV 0.89.
- 남은 수동 단계(발행 전): 본인이 겪은 디테일 1개 주입 권장. 예를 들어 4번 청구 URL을 검토하게 된 계기(새움 학부모에게 sdij 주소가 그대로 노출되는 문제인지 등)는 본인 확인이 필요해서 문안에 넣지 않았다.
