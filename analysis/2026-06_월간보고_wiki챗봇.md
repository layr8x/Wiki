## ■ 6월 개발 완료 (해당 항목을 개발 완료 목록에 추가)

### AMS 운영도우미 (직원용 위키)
- AI 의미 검색 도입 — 키워드 불일치에도 위키 전체에서 답을 찾아주는 검색
- 검색·요약 기능 통합 및 배포 안정화, 가이드 콘텐츠 확충(135건)

### 마이클래스 도우미 (재원생 챗봇)
- 기획서 v6 기준 **4개 메뉴**(출결·보강 / 납부·결제 / 수업·시간표 / 전반) 시나리오 확정
- 학생·학부모 프로토타입 제작·동기화 및 디자인 시스템 100% 정합 작업
- **1차(조회) 범위 개발 완료 → dev 검수 통과**(블로커 0, 챗봇 내 직접 처리 없이 조회·연결로 동작함을 확인)
- 도입 근거 데이터 분석 — 전화 상담 최다 문의(출결 30.7%·입반 22.0%)를 앱 조회로 흡수 가능함을 실측

### 카카오 상담 데이터 수집
- 수집 트리거를 GitHub Actions → Supabase Edge Function으로 전환(상시 가동, 매월 사용시간 소진으로 멈추던 이슈 해소)
- 라이브 수집 누적 **85,936메시지 / 7,291대화**(3개 서비스 채널), 자동 분류 적용률 98.7%

## ■ 6월 예정 업무 (★ wiki·챗봇 강조 — 진행/예정에 추가)

### 마이클래스 도우미 (재원생 챗봇) — 사용자 공개 서비스
- **1차 론칭**: 검수 후속 경미 수정(빈 화면 만족도 노출 규칙·내 시간표·전체 회차 표기 등) 후 오픈 〔론칭 시점: 개발팀 협의〕. 1차는 **조회 중심** — 출결·보강·납부·시간표를 앱에서 셀프 확인.
- **2차(현업 협의 후)**: 조회 후 **직접 신청·변경 처리** 연계(타반보강 신청·반 변경 등). 1차 논의 시 "데스크 처리 업무가 많아 챗봇 범위는 현업과 추가 논의 필요"라는 공통 의견에 따라 1차를 조회로 한정, 처리 연계는 2차로 계획.
- **생성형 AI(LLM) 기반 자연어 응대 고도화 검토** — 인프라 여건상 2차 범위로 계획 〔적용 위치: 사용자/직원 챗봇 중 확정 필요〕.
- **AMS 상담관리 연동**: 자가해결 종료 건은 미기록, 상담 연결 건만 자동 레코드 → 챗봇 전환율(자가해결률)·전화 상담 감소량 측정 체계 마련.

### AMS 운영도우미 (직원용 위키)
- 검색 고도화 및 가이드 콘텐츠 지속 확충
- 직원 업무 동선 개선을 위한 AMS 좌측 메뉴(LNB) 리디자인 제안 검토
