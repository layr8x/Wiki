# Design

시각 시스템의 SSOT는 생성기다: `build_deck.py`(슬라이드·CSS)와 `charts.py`(도표·카드 스펙 `CARD_CSS`). 산출물 HTML을 직접 수정하지 않는다 — 생성기를 고치고 재빌드한다.

## Canvas
1280×720 고정 슬라이드 16장. 패딩 60/76(증거 슬라이드 48/76), 카드 간격 24, 4pt 그리드.

## Color
라이트 단일 테마(다크 금지 — 사용자 확정).

| 토큰 | 값 | 역할 |
|---|---|---|
| --ink | #12141c | 제목·대형 수치 |
| --ink2 | #3f4450 | 본문 |
| --ink3 | #6b7280 | 보조 텍스트(화이트 위 4.83:1) |
| --canvas | #eef0f4 | 슬라이드 배경 |
| --card / --cardline | #ffffff / #e7e9ef | 카드 면·테두리 |
| --acc | #1f4fd6 | 브랜드 블루 = 우리 결정 |
| --alert(WARM) | #cd3f14 | 위험·반례 데이터 전담(4.86:1) |
| --good | #0f7a45 | 긍정·통과 |
| --navy | #101b3c | 히어로 카드·다크 필 |
| TRACK | #edeff4 | 차트 트랙(컨테이너) |
| DGRAY | #868e9c | 데이터 등급 그레이(3.3:1) |

블루 풀블리드(커버·요청 슬라이드 한정): linear-gradient(155deg, #2b50f5, #1a35c4).

## Typography
Pretendard Variable(45–920) base64 임베드 — CDN 의존 금지. `font-variant-numeric: tabular-nums` 전역. 스케일: 캡션 12 / 보조 12.5–13.5 / 본문 14.5 / 카드 제목 15.5 / h2 40–42 / KPI 값 76 / 미니 값 66 / 커버 h1 72. 자간 -0.012em 기본, 대형 수치 -0.035em.

## Components
- **card**: 화이트, radius 16, 헤어라인 + 소프트 섀도(0 1px 3px rgba(18,20,28,.05)), 헤더(제목+설명, 우측 태그 필) + 본문 SVG + 각주(.cf)
- **mini**: 스탯 카드 — 라벨(12, 자간 .14em) / 값 66 / 하단 캡션. `.mv.warm`은 위험 수치
- **kpi**: Stripe형 4열, 첫 카드는 navy 히어로. 델타 행 = 라인 아이콘(SVG stroke) + 색 텍스트
- **chart**: SVG viewBox = 실제 렌더 폭(648 내부/1076 전폭). 트랙+필 컬럼(값 상단 라벨), 도넛(중앙 수치+범례), 노치 미터(그라데이션 밴드), 플라이아웃 툴팁(feDropShadow)
- **tag/pill**: 틴트 배경 + 진한 동계 텍스트, radius full

## Depth
단일 섀도 토큰 + 헤어라인. 레이어드 섀도·글래스모피즘 금지. 플라이아웃 툴팁만 예외적 드롭섀도.

## Motion
정적 문서(덱·PDF) — 모션 없음. 인터랙션 시안은 별도 파일(AMS챗봇_알림바_인터랙션시안_최종.html) 관할.

## 금지
다크 테마, 이모지 아이콘, 그라데이션 텍스트, 사이드 스트라이프 보더, 임의 신규 색. 도표 팔레트 변경 시 dataviz 검증기 재통과 필수.
