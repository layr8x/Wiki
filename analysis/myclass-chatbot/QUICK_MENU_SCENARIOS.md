## 0. v6 4메뉴 축소 배경 (8메뉴 → 4메뉴)

옛 8메뉴(v3)는 디지털 채널 분포를 그대로 메뉴로 옮겼으나, **인앱 챗봇의 도달 한계**를 반영해 v6에서 4메뉴로 확정됐다.

| 옛 8메뉴 | 전화(AMS) | 오픈채팅 | v6 처리 |
|---|---:|---:|---|
| 🔑 계정·로그인·앱 | 0.2% | 37.1% | **삭제** - 로그인 **전** 발생 → 인앱 챗봇 못 닿음 |
| 💳 미납·결제·환불 | 8.2% | 12.2% | **② 납부·결제**(축소) |
| ✏️ 입반·등록·대기 | 28.3% | 7.6% | **삭제**(입반 강좌 **확인**만 ① 출결·보강으로 흡수) |
| 📡 라이브 | 14.9% | 6.0% | **삭제**(별도 라이브 서비스) |
| 📦 교재·배송 | 1.2% | 5.3% | **삭제** |
| 📋 출결·보강 | 30.7% | 3.1% | **① 출결·보강**(조회 기능) |
| 📅 시간표·수업 | 3.1% | 0.2% | **③ 수업·시간표**(조회) |
| 🔄 퇴원 | 9.0% | 0.2% | **삭제**(전반 대안만 ④ 전반) |
| 🎧 일반·기타 | 2.7% | 28.3% | **삭제**(FAQ 별도 메뉴 없음, 상담 연결) |

**v6 원칙 3가지:**
1. **인앱에서 닿을 수 있는 것만.** 로그인 전 수요(계정·로그인)는 챗봇이 못 잡음 → 메뉴에서 제외. 흡수 타깃 = 전화의 출결·보강·결제·시간표(+전반 대안).
2. **결제는 "이탈 막기"가 아니라 "도와주기".** 실사용자 결제완료 ~80%(정상). 가치 = 납부 현황·결제 내역 조회 + 재시도 마찰 완화.
3. **모든 조회는 강좌 단위 키.** AMS 상담이 '특정 선생님 강좌' 단위로 일어남.

**공통 UX(SERP-8270, 모든 화면):** ①2Depth 이상 = [이전]+[처음으로] 둘 다 ②헤더 [홈] 버튼 삭제(닫기 X만) ③상담 = **[상담 연결](전화, 지점별 번호)** 하나만 ④아이콘 Material Symbols Rounded weight 300.

### 1. 📋 출결·보강 - **전화 1위 30.7% + 입반 확인 흡수**
```

[오늘 출석 확인] [강좌 선택] [입반 강좌 확인]

   · 출석 전 → "출석예정" · 수업 없음 → 고정문구

[강좌 선택] (at_course) → 봇:"어떤 강좌를 확인할까요?" + 강좌칩
```

## 4. 공통 규칙
- **막다른 길 금지(현재 0)**: 모든 카드 하단에 다음 행동([이전][처음으로], 데이터 없음도 안내 문구+버튼).
