## 2. 노드별 상태(상태 조건)·답변·버튼 (요약, 문구 정본=xlsx)

### 출결·보강
- **오늘 출석 확인**
  - 수업 있음+출석: `오늘(M/D) 출석 현황이에요.` + 강좌카드(수업 시각 / 출석 HH:MM). 버튼 `[처음으로]`
  - 수업 있음+출석전: 상태 = **`출석예정`** 고정(체크인 전). `[처음으로]`
  - 수업 없음: `오늘(M/D)은 수업이 없어요.` `[처음으로]`
- **강좌 선택**: 있음 → `어떤 강좌를 확인할까요?` + 강좌 버튼들 / 없음 → `현재 수강 중인 강좌가 없어요.`
- **강좌 선택 후(항상)**: `어떤 내용을 확인할까요?` → 고정 버튼 3개 **[동영상 보강][타반보강][추가영상]**, 선택 강좌명 상단 표시
  - **타반보강**: 일정 있음 → `%강좌명% 타반보강 가능 일정이에요.` + `N회차 | M/D (요일) | 시작~종료 | 강의실`(내 수업 이후 시간대만·날짜 오름차순). `[처음으로]` / 없음 → `…타반보강 가능한 일정이 없어요. 문의는 상담실로…` `[상담 등록][전화 상담 연결][처음으로]`
  - **동영상 보강**: 있음 → `%강좌명% 동영상 보강 내역이에요.` + `N회차 | 지급일 M/D | 시청 기한 M/D %상태%`(최신순). `[처음으로]` / 없음 → 고정문구 `[처음으로]`
  - **추가영상**: 동영상 보강과 동일 형식(지급일+시청기한 둘 다). `[처음으로]`

### 입반·등록·대기
- **입반 강좌 확인**: 있음(완납) → `입반된 강좌 현황이에요.` + `%강좌명%`(완납 건 결제버튼 미노출·배지 없음·여러 개면 카드 반복) `[처음으로]` / 없음 → `현재 입반된 강좌가 없어요.` `[처음으로]`
- **강좌 선택**: 있음/없음 동일 패턴.

### 납부·결제
- **납부 대기 현황**: 납부대기 있음 → `%강좌명% 납부 현황이에요.` + `[납부대기] %청구금액%원 · 기한 %납부기한%`(천단위 콤마·오늘이면 `오늘 마감` 병기·미납/완납 섹션 분리·**납부는 앱에서 진행 안내**). `[납부하기][처음으로]` / 전체 완납 → `모든 수강료가 납부 완료됐어요.` `[처음으로]`
- **결제 내역**: 있음 → `최근 3개월 결제 내역이에요.`(+총합계 노출) + `YYYY-MM-DD | 강좌명 | 금액원 | 결제수단(카드사)`(최신순·카드면 카드사 병기·가상계좌/현금은 괄호 미노출·"최근 3개월" 상단 고정). `[처음으로]` / 없음 → `결제 내역이 없어요.` `[처음으로]`

### 수업·시간표
- **내 시간표**: 있음 → `이번 주(M/D~M/D) 시간표예요.` + `요일 시작~종료 강좌명 · 강의실`(요일순·강좌 없는 요일 미출력). `[다음 주 보기][처음으로]` / 없음 → 고정문구 `[다음 주 보기][처음으로]`
- **종강일 확인**: 있음 → `강좌별 종강일이에요.` + `%강좌명% → YYYY-MM-DD` + 하단 `휴강·일정 변경은 상담실로…` 고정. `[상담 등록][전화 상담 연결][처음으로]` / 없음 → 고정문구.
- **강좌별 전체 회차 일정**: 강좌 선택 → `%강좌명% 전체 일정이에요.` + `N회차 | M/D (요일) | 시작~종료` … + `전체 N회 중 M회차 진행 중`(현재 회차 표시). `[다른 강좌 보기][처음으로]`

### 전반
- **시간이 안 맞아요**: 강좌 선택(`%강좌명% - 요일 시각`) → 같은 강사 타 시간 **있음** → `%강사명% 선생님의 다른 시간대 강좌예요.` + 강좌/요일·시각 + `반 변경 신청은 상담을 통해…`(잔여석 0이면 `마감`). `[상담 등록][전화 상담 연결][처음으로]` / **없음** → `현재 %강사명% 선생님의 다른 시간대 강좌가 없어요…` 동일 버튼.

## 4. 에러 처리 정의 (6)
1. 데이터 조회 실패 → `일시적인 오류가 발생했어요. 잠시 후 다시 시도해 주세요.` `[다시 시도][처음으로]` (3회+ 실패 시 상담 연결 추가)
2. 응답 지연(10초+) → `데이터를 불러오는 중이에요…`(로딩, 15초 후 오류 전환)
3. 부분 조회 → `일부 정보를 불러오지 못했어요. 확인된 내용만…` `[다시 시도][처음으로]`
4. 네트워크 끊김 → `인터넷 연결을 확인해 주세요…` `[다시 시도]`
5. 상담 등록 실패 → `상담 등록 중 오류가… 전화로 직접 문의해 주세요.` `[전화 상담 연결][처음으로]`(등록 실패해도 전화는 항상 가능)
6. 점검 중 → `현재 서비스 점검 중이에요…` `[전화 상담 연결]`
