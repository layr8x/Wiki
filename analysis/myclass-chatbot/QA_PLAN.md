> **목적**: 이 문서는 같은 저장소의 `public/myclass-chatbot.html`(학생) / `public/myclass-chatbot-parent.html`(학부모) - **인터랙티브 v6 4메뉴 빌드, SSOT** - 를 **그대로 들고 검증**하는 실행 체크리스트다.

## 0. 문서 사용법 (테스터 가이드)

| 표기 | 뜻 |
|---|---|
| **Tier** | T1 즉답(가이드) / T2 개인화 조회(로그인 컨텍스트) / T3 상담 연결(전화) |
| **라우팅** | auto(바로 분기) / disamb(되묻기) / human(상담 연결) |
| **PASS 조건** | 기대결과가 화면에 그대로 나타나고, 카드 하단에 다음 행동이 1개 이상 존재 |
| **FAIL 조건** | 막다른 길 발생 / 의도치 않은 개인정보 노출 / 카피 불일치 / JS 콘솔 에러 |
| **P0~P3** | 심각도. P0=출시 차단, P1=출시 전 필수, P2=출시 후 빠른 수정, P3=개선 |

테스트 환경(반드시 이 위에서 실행):
- **3뷰 전환기(viewswitch)**: 화면 상단 토글로 **모바일 / 태블릿 / 데스크탑** 전환. 모든 핵심 플로우는 3뷰 모두에서 통과해야 한다.
  - 모바일: 바텀시트(90% 높이) · 드래그 핸들로 닫기. 기준폭 400px.
  - 태블릿·데스크탑: 우하단 **도킹 패널 392×700**(화면 넘으면 자동 축소) · 닫기 버튼으로 닫기.
- 기기: 모바일 우선(데이터상 모바일+태블릿 95.8%). iPhone Safari · Android Chrome.
- 화면폭: 360px(최소) · 390px · 414px · 430px(최대).
- 네트워크: 정상 / 느린 3G / 오프라인(엣지케이스용).
- **디자인 대조 도구**: `tools/design-audit/render.cjs`·`compare.py`·`screens.json`(Figma 노드 지도). 화면 정합은 반드시 이 도구로 400px 1:1 대조(7장).

> 메뉴 4개 key 순서(`MENU` 배열): `attend · pay · time · overall`. (옛 8메뉴 `account·enroll·live·quit·help`는 v6에서 **삭제** - '입반 강좌 확인'만 출결·보강으로 흡수.)
> v6에는 진입 배너·'자주 찾는 것' 칩·3채널(카톡) 라우팅이 **없다**. 홈 = 인사말(heroGreet) + 4타일 메뉴그리드만. `setBanner()`는 배너 슬롯을 비운다.

### 2.2 Out-of-Scope (이번 검증에서 제외)

- 실제 백엔드 API 응답 정합성(납부·시간표·보강 등) - 현재는 **목업/더미 데이터** 기준, UX·폴백만 검증. (`BACKEND_INTEGRATION.md` 참조)
- 정밀 PG(결제 모듈) 트랜잭션 - 외부 '납부하기' 결제창 왕복은 "안내·복귀 UX"만 검증.
- 실제 전화 연결(tel:) 이후 통화 - 딥링크(tel:) 열림까지만 검증.

### 2.3 도달해야 하는 화면 목록(전수) - 4메뉴 실제 빌드 기준

각 메뉴의 정상 화면 + 빈 상태 + 종료(만족도/상담) 분기까지 전부 클릭 도달 확인. (노드ID = SSOT 함수명)

- **공통/진입**: `home`(4타일) · 열기(바텀시트/도킹) · 닫기 · 만족도(😄/😭) · 상담 연결 모달 · 지점/자녀 전환.
- **출결·보강**(`m_attend`): `at_today`(오늘 출석/빈=수업없음) · `at_course`→`atAfter`(빈=입반 중인 강좌 없음) · `atOther`(타반보강/빈=상담) · `atVideoMakeup`(동영상보강/빈) · `atVideoExtra`(추가영상/빈·'준비 중' 흐림) · `en_check`(입반 강좌 확인/빈).
- **납부·결제**(`m_pay`): `pay_wait`(납부현황 2섹션/전체완납) · `pay_history`(결제내역+더 보기/빈).
- **수업·시간표**(`m_time`): `time_table`(이번/다음 주 토글/빈) · `time_rounds`→`roundsResult`(빈) · `time_end`(종강일/빈).
- **전반**(`m_overall`): OVERALL 강좌 선택 → `altResult`(다른 시간대/빈).

> ⚠️ 엔진 생성 노드는 metadata grep에 안 잡히므로 **화면 도달 검증은 스크린샷**으로 한다(CLAUDE.md 7장·15장). 위 목록을 체크리스트로 전수 클릭.
