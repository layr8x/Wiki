# 마이클래스 챗봇 론칭 상태 리뷰

작성: 조호영 · 2026-06-30

## 한 줄 결론

현재 챗봇은 **조회 기능까지 구현이 끝났고, QA에서 막는 이슈(론칭 블로커)가 0건이라 오픈 가능한 상태**입니다. 다만 6월 상담을 전수로 분석해 보니 사용자가 가장 많이 겪는 문제(계정·번호, 신청)는 아직 챗봇이 처리하지 못합니다. 그래서 1차는 **"조회 셀프서비스 + 계정 문제 안내"** 형태로 오픈하는 것을 제안드립니다. 상담량을 크게 줄이는 효과는 신청·처리 기능이 들어가는 2차부터 나옵니다.

---

## 1. 어디까지 구현됐나

조회 영역 4개 메뉴와 보강 화면까지 구현을 마쳤고, dev 환경에서 직접 검수했습니다.

| 메뉴 | 화면 | 상태 |
|---|---|---|
| 출결·보강 | 오늘 출석 · 동영상보강 · 타반보강 · 추가영상 · 입반 강좌 확인 · 재수강 확인 · 대기번호 확인 | 구현 완료 |
| 납부·결제 | 납부 현황 · 결제 내역 (조회) | 구현 완료 |
| 수업·시간표 | 내 시간표 · 전체 회차 · 종강일 · 강의실 안내 · 설명회/컨설팅 일정 | 구현 완료 |
| 전반 | 전반 가능한 강좌 조회 | 구현 완료 |

- **QA 결과(6/30)**: 론칭 블로커 0건. 경미한 수정 5건(빈 화면 안내 문구 등)만 반영하면 1차 론칭 가능합니다.
- **아직 안 된 것**: 신청·등록·결제·취소 같은 **처리 기능**과 **계정·번호 매칭 수정**은 1차 범위에 없습니다. 챗봇은 현재 "내 정보 조회"까지만 합니다.

---

## 2. 데이터로 본 오픈 효과 (6월 상담 전수 분석)

전화 상담 81,863건(AMS 기록)과 카카오 상담 162개 대화를 전수로 분석했습니다. 특히 카카오는 대화를 한 건씩 직접 읽어 분류했습니다.

**카카오 채널 162개 대화를 성격별로 나누면:**

| 성격 | 대화 | 비중 | 지금 챗봇이 푸나 |
|---|---:|---:|---|
| 조회(출결·시간표·납부·보강 등) | 19 | 12% | ✅ 가능 |
| 신청·변경·취소·결제 | 47 | 29% | ❌ 2차 기능 필요 |
| **계정·번호 문제** | **63** | **39%** | ❌ 가입·접수 수정 필요 |
| 사람 상담(환불 협의 등) | 17 | 10% | ❌ 사람 |
| 인사·노이즈 | 16 | 10% | — |

정리하면, **지금 챗봇(조회)이 바로 해결하는 건 약 12%**입니다. 사용자가 카카오로 가장 많이 문의하는 건 **계정·번호 문제(39%)**인데, 이건 챗봇 화면이 아니라 가입·접수 단계를 고쳐야 풀립니다.

> 계정·번호 문제란: 앱에서 자녀 정보가 안 보이거나, "이미 등록된 번호"라 가입이 막히거나, 결제·수강 문자가 한쪽 번호로만 가서 번호를 바꾸려는데 앱에서 안 되는 상황입니다. 학생·학부모가 각자 가입하면서 번호 연결이 어긋나 생깁니다.

**전화 채널**은 조회·질문형 문의가 월 16,429건(전체의 20%)으로, 이 부분이 챗봇으로 옮겨올 수 있는 대상입니다. 다만 전화 사용자를 앱 챗봇으로 유도해야 실제 감소로 이어집니다.

→ **솔직하게, 1차 오픈만으로 상담량이 크게 줄지는 않습니다.** 가장 많은 문제(계정·신청)를 1차 챗봇이 못 풀기 때문입니다.

---

## 3. 1차 오픈 제안 — 조회 + 계정 문제 안내

그래서 1차는 다음 형태를 제안드립니다.

1. **조회 셀프서비스 오픈** — 출결·시간표·납부·동영상보강 등을 앱에서 바로 확인. 이 부분은 완성도가 충분하고 사용자 편의가 분명합니다.
2. **계정·번호 문제 안내 경로 추가** — 가장 많은 문제(39%)를 챗봇이 완전히 풀진 못해도, "계정·번호가 안 맞을 때는 이렇게 하세요"라는 안내 경로(원인 안내 + 본인인증/문의 연결)를 넣습니다.

이렇게 하는 이유는, **사용자가 챗봇을 열었다가 자기 문제(계정)는 못 풀고 그냥 나가는 상황을 막기 위해서**입니다. 공개 서비스라 첫인상이 중요한데, 가장 흔한 문제가 막다른 길이 되면 안 됩니다.

**1차 기대 효과(과장 없이)**: 조회 문의 셀프 처리 + 계정 문제 사용자의 이탈 방지. 상담량의 큰 감소가 아니라, **조회 편의 제공과 안전한 첫 오픈**이 목표입니다.

---

## 4. 2차 계획 — 여기서 실제 효과가 납니다

| 추가 기능 | 효과 |
|---|---|
| 신청·변경·취소·결제 처리 | 카카오 대화의 29%, 전화 처리형 월 25,828건을 추가로 흡수 |
| **계정·번호 매칭 수정**(가입·접수 프로세스) | 카카오 최대 문제 39%의 발생 자체를 줄임 |

2차까지 가면 카카오 문의의 **약 80%**를 제품(챗봇 + 계정 수정)으로 대체할 수 있습니다. 남는 약 20%는 환불 협의처럼 사람이 판단해야 하는 문의라, 챗봇 안에서 "요청 접수 → 1:1 답변"으로 받으면 됩니다.

특히 **계정·번호 매칭 수정은 챗봇 화면을 더 만드는 것보다 효과가 큰 작업**입니다. 가장 많은 문제를 발생 단계에서 줄이기 때문입니다.

---

## 5. 정리 · 다음 액션

- **1차(지금)**: 조회 챗봇 + 계정 문제 안내 경로로 오픈. QA 경미 5건 수정.
- **2차**: 신청·처리 기능 + 계정·번호 매칭 수정 → 카카오 80% 대체.
- 오픈 후에는 실제 사용량과 상담 감소를 같이 보면서 효과를 확인하겠습니다.

| 구분 | 1차(지금 오픈) | 2차 |
|---|---|---|
| 챗봇이 해결 | 카카오 약 12% / 전화 조회 월 16,429건 대상 | 카카오 약 80% / 전화 +월 25,828건 |
| 필요 작업 | QA 5건 + 계정 안내 경로 | 처리 기능 + 계정 매칭 수정 |
| 목표 | 조회 편의 + 안전한 첫 오픈 | 상담 대체 본격화 |
