### 제목
[MY] 챗봇 - 도입 효과 분석 (카카오 상담 대체율·오픈 여부 판단)

### 설명

**목적**
마이클래스 챗봇이 카카오 상담 채널을 어디까지 대체할 수 있는지 데이터로 산출하고, 정식 오픈 시점과 범위를 판단하는 기초자료를 만듭니다.

**분석 대상 데이터**
- 카카오 상담: 전체 기간(2025-12-22 ~ 2026-07-01) 1,658건, 6월 162건. 두 기간 모두 대화를 한 건씩 정독해 분류.
- 전화(AMS) 상담: 6월 81,863건 전수 (참고용).
- 챗봇 dev QA 결과 (2026-06-30 검수).

**분석 방법**
- 대화를 챗봇 역량별 5개 버킷(조회·계정·처리·사람·노이즈)으로 전수 분류. 분류 에이전트 다수 + 별도 검증자의 적대 검증으로 과대분류 방지.
- 표본 불확실성은 Wilson 95% 신뢰구간으로 표기.
- 운영 데이터베이스를 다시 조회해 재검증(163건, 오차범위 안에서 일치).
- 원본 CSV에서 모든 핵심 수치를 독립 재집계해 교차검증(불일치 0건).

**주요 결과**
- 1차 오픈(조회 챗봇 + 계정·번호 매칭 수정): 카카오 빈번 문의 50%에서 60% 대체.
- 2차 오픈(신청·변경·결제 처리 기능 추가): 80%에서 88% 대체.
- 최대 문제는 계정과 번호 문제(6월 39%, 전체 기간 52%). 로그인 전에 생기므로 앱 밖(로그인 화면·카카오 채널·도움말)에도 대응이 필요.
- 챗봇 준비도: 론칭을 막는 결함 0건, 경미 수정 5건과 재검수 1회 후 1차 오픈 가능.

**산출물**
- Confluence: 도입 효과_26.06
- 보고서: `오픈단계별_대체효과_factsheet.md`, `마이클래스챗봇_6월상담_심층분석_컨플루언스.md`, `챗봇답변_로그인전후_구성.md`, `마이클래스챗봇_오픈여부_결정메모.md`
- 시연: `2026-06_챗봇_시연_필름스트립.png`, `.html` (6월 상위 조회 문의 8개를 챗봇 화면으로 시연)

## 이슈 2

### 제목
[MY] 챗봇 - FAQ 추가안 도출 (카카오 문의 데이터 기반)

### 유형 / 라벨 (권장)
- 유형: Task
- 라벨: myclass-chatbot, faq, kakao
- 연결: 이슈 1 (도입 효과 분석)에서 파생

### 설명

**목적**
카카오 상담 데이터에서 자주 묻는 주제를 뽑아, 챗봇과 앱 FAQ에 추가할 질문과 답변을 도출합니다.

**배경**
현재 FAQ는 영상 재생 문제(카카오 수요 4.9%)와 결제 무이자 할부(0.1%)로 이 채널에서는 수요가 낮습니다. 실제로 가장 많이 묻는 것은 계정과 로그인 문제(44.5%), 그리고 라이브 신청·대기·환불 같은 절차 문의입니다.

**분석 방법**
- 전체 기간 1,658건에서 세부주제 14종의 빈도를 대화 단위로 집계.
- 정적 FAQ로 답이 되는 주제(절차·정책)와 개인 데이터 조회(로그인 후 챗봇 담당)를 구분.
- 수요 큰 순과 FAQ 해결도로 우선순위화. 키워드 집계 오염 사례(학원 연락처 표면 24% → 실제 2.8%)는 정밀 재확인으로 제거.

**주요 결과**
- FAQ 추가안 18개 항목, 5개 탭: 계정·로그인 7, 앱·재생 2, 수강·대기·보강 4, 결제·환불 2, 기타 3.
- 각 항목마다 질문과 답변(습니다체) 작성.
- 최상위 항목: 자녀 정보 안 보임 23.6%, 로그인 안 됨 20.7%, 라이브 신청 14.6%, 앱 설치·업데이트 13.7%.
- 핵심 방향: 저수요 주제(영상·할부)에서 최다 수요(계정·로그인·절차)로 무게중심 이동.

**산출물**
- 보고서: `FAQ_최종정리본.md`(게시용 18항목), `FAQ_추가안_질문답변.md`
- 데이터: `kakao_세부주제_빈도.csv`, `kakao_FAQ추가_우선순위.csv`, `kakao_FAQ흡수분석.csv`
- 임포트용: `kakao_FAQ_추가안.csv` (탭·질문·수요·답변 4열, 18항목)

**게시 전 확인 사항**
- 답변의 앱 메뉴 경로(전체메뉴·내 정보·학원 등록 정보 연동 등)를 실제 앱 화면 기준으로 최종 확인.
- 지점 전화번호는 지점마다 달라 비워 두었으므로 게시 시 채움.
- 계정과 번호가 실제로 꼬인 경우는 상담 연결로 폴백. 앱에 계정 매칭 수정 기능이 생기면 그 동선으로 교체.

**후속 작업**
- 계정·로그인 FAQ는 로그인 전에 닿는 위치(로그인 화면·카카오 채널·도움말)에도 노출(로그인 전후 답변 구성 문서 연계).
- 오픈 후 FAQ 셀프 해결률(특히 영상 재생 개강기, 계정·로그인)을 측정해 항목 보강.

## 이슈 3

### 제목
[MY] MYCLASS 로그인 화면 하단 - 로그인 문제 해결 UI 추가

### 유형 / 라벨 (권장)
- 유형: Task / 담당: @김명준(디자인), 프론트
- 라벨: myclass, login, faq

### 설명

**목적**
로그인 전 단계에서 생기는 계정·로그인 문의를 로그인 화면에서 바로 안내합니다. 이 채널 최대 문의인 계정·로그인 문제(카카오 44.5%)는 앱이 사용자를 알아보기 전에 발생하는데, 챗봇은 로그인 후에만 동작하므로 로그인 화면(로그인 전)에 도움 동선이 필요합니다.

**요구사항**
- 로그인 랜딩 페이지(재원생 전용)의 로그인 버튼 아래에 "로그인 문제 해결" 링크를 노출합니다.
- 링크를 누르면 안내 모달을 띄웁니다. 모달 내용은 다음과 같습니다.
  - 통합회원 아이디 하나로 여러 서비스를 이용한다는 안내
  - 아이디는 가입 시 이메일이며, 아이디 찾기와 비밀번호 재설정 안내
  - 로그인 후 정보가 안 보이는 경우: 로그아웃 후 앱 종료, 재로그인, 학원 등록 정보 연동 안내
- 모달 하단 버튼: 아이디 찾기, 비밀번호 재설정
- 반응형: 데스크탑, 태블릿, 모바일 3뷰 모두 지원

**추가 권장 (분석 기반)**
- 모달 하단에 문의하기 또는 상담 연결 경로를 추가합니다. 계정·번호 꼬임은 아이디 찾기와 비밀번호 재설정으로 해결되지 않는 경우가 많고, 로그인 전이라 챗봇도 사용할 수 없어 탈출구가 없으면 막다른 화면이 됩니다. 로그인 화면에 이미 카카오 채널 진입 동선이 있으면 생략 가능합니다.

**완료 조건**
- 3뷰에서 링크와 모달이 정상 노출되고 열림과 닫힘이 동작합니다.
- 아이디 찾기, 비밀번호 재설정 링크가 실제 기능으로 연결됩니다.
- 모든 종단에 다음 행동이 있어 막다른 길이 없습니다.

**근거 / 연결**
- Confluence: 도입 효과_26.06, FAQ 추가안_26.06
- 분석 문서: 챗봇답변_로그인전후_구성.md (로그인 전 답변 배치), FAQ_최종정리본.md (로그인이 안 돼요 답변)

## 이슈 4

### 제목
[MY] 챗봇 - MYCLASS 챗봇 FAQ 기능 추가

### 유형 / 라벨 (권장)
- 유형: Task / 담당: @김명준(디자인), 프론트
- 라벨: myclass-chatbot, faq

### 설명

**목적**
챗봇에 FAQ를 추가해 자주 묻는 조회와 절차 문의를 셀프 해결로 돌립니다. 현재 FAQ는 카카오 수요가 낮은 주제(영상 재생, 결제 할부)에 치우쳐 있어, 실수요가 큰 계정·로그인과 절차 문의를 담은 FAQ가 필요합니다.

**요구사항**
- 챗봇 홈 메뉴에 "자주 묻는 질문" 타일을 추가합니다.
- 타일을 누르면 FAQ 화면으로 이동합니다.
- FAQ 화면 상단 탭: 전체, 계정·로그인, 수강·대기·보강, 앱·재생, 결제·환불, 기타. 전체 탭을 기본으로 하고, 카테고리 탭은 해당 항목만 필터해서 보여줍니다.
- 각 항목은 질문을 누르면 답변이 펼쳐지는 아코디언 형태입니다.
- 콘텐츠는 FAQ 추가안 18개 항목과 답변을 사용합니다. 자주 묻는 순으로 노출합니다(자녀 정보 안 보임, 로그인 안 됨, 라이브 신청, 앱 설치·업데이트 순).
- 반응형: 데스크탑, 태블릿, 모바일 3뷰 지원

**완료 조건**
- 홈 타일에서 FAQ로 진입됩니다.
- 탭 선택 시 해당 카테고리만 노출됩니다(전체는 모두 노출).
- 18개 항목과 답변이 정확히 노출됩니다(오탈자, 답변 누락 없음).
- 개인 데이터가 필요한 답변은 로그인 후 앱에서 확인하도록 안내합니다.

**근거 / 연결**
- Confluence: FAQ 추가안_26.06
- 임포트 데이터: `analysis/kakao-collect/data/kakao_FAQ_추가안.csv` (탭, 질문, 수요, 답변 4열, 18항목)
- 분석 문서: FAQ_최종정리본.md, kakao_세부주제_빈도.csv

**요구사항**
- 하단 검색에서 FAQ와 전체 가이드를 함께 검색합니다.
- 검색 결과 리스트의 각 항목에 전체 가이드 또는 FAQ 뱃지를 붙여 출처를 구분합니다.

- 화면 상단에 월별 기능 업데이트 안내 Floating 배너를 노출합니다(예: 강좌·교재관리 등 7월 기능 업데이트 안내, 바로가기 링크).
- 상단 메뉴 구성은 회의 결정대로 반영합니다(상단은 FAQ 메뉴, 하단 검색은 FAQ와 전체 가이드 통합).

**완료 조건**

- 검색 결과에 출처 뱃지가 정확히 표기됩니다.
- 가이드 선택 시 카드와 후속 안내가 노출됩니다.
- 상단 기능 업데이트 배너가 노출되고 바로가기가 연결됩니다.

**근거 / 연결**
- 2026-07-01 회의 결정
- 연계: AMS 위키 가이드·FAQ(ds26)
