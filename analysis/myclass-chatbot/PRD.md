## 0. 한 페이지 요약 (Executive Summary)

| 항목 | 내용 |
|---|---|
| **무엇** | 마이클래스 앱(`myclass.sdij.com`) **안에서 뜨는 인앱 챗봇** — 학부모·학생이 막혔을 때 자가 해결, 안 되면 맥락 그대로 상담원 연결 |
| **왜** | 전화 상담 **96.7%**(셀프서비스 미충족). 디지털 채널에선 **계정·로그인·앱이 36.7%로 1위** — 앱 안에서 막히는데 도울 길이 없음 |
| **핵심 가치** | ① 디지털 1위(계정·앱) 셀프 트러블슈팅 ② 미납 회수 + 결제 재시도 마찰 완화 ③ 핸드오프 시 "재질문 0" (맥락칩 자동 첨부) |
| **북극성 지표** | **전화 접수 비중 96.7% → 흡수**(셀프 자가해결률 + 핸드오프 품질로 측정) |
| **MVP 범위** | 메뉴 8개 + 온보딩 + 상담원 핸드오프(3단계) + 능동알림 3종(N2·N4·N1) |
| **기한** | 6/18 개발팀 핸드오프(콘텐츠·플로우·디자인 확정본) |

**설계 3원칙** (시나리오 v3 확정):
1. **앱에서 막히는 것(계정·결제·입반)을 앞으로.** 전화 1위 출결은 뒤로 — "회차/강좌 조회 + 문자 재발송"형 *조회 기능*으로 유지.
2. **결제는 "이탈 막기"가 아니라 "도와주기".** 실사용자 결제완료 **~80%**(정상). 가치 = 미납 회수 + 재시도 마찰 완화 + 외부 결제모듈 안내.
3. **모든 조회는 강좌 단위 키.** AMS 상담이 '특정 선생님 강좌' 단위로 일어남.

## 1. 배경 · 문제 · 목표

### 1.1 배경 — 3채널 데이터 교차검증

세 개의 독립 데이터가 **같은 결론**으로 수렴(`DATA_ANALYSIS.md` §6 삼각검증).

| 소스 | 규모 | 무엇을 알려주나 |
|---|---|---|
| **AMS 상담**(상담실장 기록) | 424,200건 / 중분류 99종 | 무엇을 물어보나(케이스 유니버스). 전화 96.7%·학부모 92.1% |
| **카카오 오픈채팅**(파트너센터 스트림) | 7,213 대화 / 85,049 메시지 | 디지털 채널 실제 상담. 챗봇이 살 환경에 가장 가까움 |
| **GA4 라이브**(BigQuery) | 세션 192.9만 / 페이지뷰 797.7만 | 어디서 막히나(행동·페이지 맥락·결제 퍼널) |

### 1.2 문제 (Problem Statement)

| # | 문제 | 데이터 근거 |
|---|---|---|
| P1 | **전화에 의존** — 셀프서비스가 없어 단순 조회까지 전화로 옴 | AMS 접수형태 **전화 96.7%**(410,104건) |
| P2 | **디지털에서 계정·앱이 막힘** — 앱 안에서 막히는데 도울 길이 없음 | 오픈채팅 **계정·로그인·앱 36.7%**(압도적 1위) |
| P3 | **결제 마찰** — 미납 잔여 + 재시도 왕복 + 외부 결제모듈 혼란 | 미납 8,954건 · 1인당 결제화면 **평균 3.37회** 재진입 |
| P4 | **입력 마찰** — 폼이 많아 진입 장벽 | `form_submit` **15.3만**건 |
| P5 | **전화 1위 출결은 사실 조회·재발송 수요** | 상담내용 최빈어 '주차 42,484·회차 20,445' = 단순 회차 조회 |

> ⭐ **중요 정정**(`DATA_ANALYSIS.md` §1.5): 초기 "결제 이탈 61%"는 **측정 착시**. 원천 이벤트 재분석 결과 실사용자 기준 결제완료 **78.6%~81.6%**(정상). 외부 결제모듈(sdijeon 공통 PG)을 GA4가 중간 구간을 못 잡았고, 1인당 결제화면 3.4회 재진입으로 이벤트가 부풀려진 것. → **결제 메뉴의 톤은 "이탈 막기"가 아니라 "도와주기".**

### 1.3 목표 (Goals)

| 구분 | 목표 | 측정(KPI) |
|---|---|---|
| **북극성** | 전화 접수 **96.7%를 셀프서비스로 흡수** | 챗봇 자가해결률 + 전화 인입 감소 |
| G1 | 디지털 1위 계정·앱을 챗봇 1급으로 자가 해결 | 🔑 메뉴 자가해결률 ≥ 목표치 |
| G2 | 미납 회수 + 결제 재시도 마찰 완화 | 미납 카드 → 결제 딥링크 클릭률 / 미납 회수율 |
| G3 | 핸드오프 시 "재질문 0" (맥락칩 자동 첨부) | 상담원 재질문률 ↓ / 핸드오프 만족도 |
| G4 | 입력 마찰 최소화 | 온보딩 2필드만 / 본인확인 완료율 |

### 1.4 비목표 (Non-Goals) — MVP 제외

- 자연어 자유 대화(LLM 생성형 답변) — MVP는 **버튼/카드 기반 결정 트리**. 분류기는 라우팅 보조용.
- LIVE 별도 사이트 *내부* 처리(결제·배송 직접 실행) — 안내·딥링크까지만(연동 범위는 §4-D4).
- 능동알림 전체 9종 — MVP는 **N2·N4·N1 3종**만.
- 결제·환불 *금액 확정* — 챗봇은 조회·안내, 확정은 상담원/규정.
