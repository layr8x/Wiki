## 0. 온보딩
**봇 발화**
- 첫 인사: "안녕하세요. 마이클래스 도우미예요 😊"
- 본인확인 안내: "안전하게 도와드리려고 학생 정보를 먼저 확인할게요. 잠깐이면 돼요."
- 입력 요청: "학생 이름과 학부모님 연락처 뒤 4자리를 알려주세요."
- 확인 성공: "확인됐어요. 무엇을 도와드릴까요?"
- 1회 불일치: "정보가 한 번 안 맞았어요. 띄어쓰기 없이 다시 한 번 입력해 주세요."
- 2회 불일치: "확인이 어려우시네요. 상담원이 바로 도와드릴게요. 연결할까요?"

**버튼**: `상담원 연결하기` · (계정·로그인 진입) `확인 없이 로그인 도움받기`
**카드**: 제목 "학생 확인" / `학생 이름` · `학부모 연락처 뒤 4자리`
**주의**: 입력 2필드만(폼 마찰 15만). 🔑계정 진입은 본인확인 우회.

## 1. 🔑 계정·로그인·앱 — 1순위 (오픈채팅 36.7%)
**봇 발화**
- 진입 배너: "로그인이 안 되시나요? 바로 도와드릴게요."
- 첫 안내: "괜찮아요, 금방 풀려요. 어디서 막히셨나요? 😊"
- [로그인이 안 돼요]: "대부분 가입하신 방법이 헷갈려서예요. 같이 하나씩 확인해 볼게요."
- [앱이 멈춰요]: "앱이 답답하셨죠. 30초면 풀리는 방법부터 해볼게요."
- [통합회원·계정연결]: "여러 시대인재 서비스를 한 계정으로 쓰는 거예요. 쉽게 안내해 드릴게요."
- [본인확인이 안 돼요]: "번호가 바뀌었거나 정보가 안 맞을 때 그래요. 상담원이 바로 처리해 드릴게요."
- 해결 확인: "이제 들어가지시나요?"
- 미해결 핸드오프: "안 되셨군요. 지금까지 확인한 내용 그대로 상담원에게 넘겨드릴게요. 다시 설명 안 하셔도 돼요."

**버튼**: `로그인이 안 돼요`·`앱이 멈춰요`·`통합회원·계정연결`·`본인확인이 안 돼요` / 하단 `해결됐어요`·`상담원 연결하기` / `가입한 방법 찾기`·`비밀번호 재설정하기`·`오류 접수하고 연결하기`·`통합회원이 뭐예요`·`지금 통합하기`·`자녀 계정 연결하기`
**카드**: "로그인 이렇게 풀어요" — ① 가입한 방법 확인 ② 비밀번호 재설정 ③ 앱 최신 버전 업데이트 ④ 통합회원 연결 필요 여부 / "가입 방법 찾기" → "휴대폰/Gmail/네이버/카카오로 가입됨" → `그 방법으로 로그인하기`
**주의**: 첫 마디는 진단이 아니라 안심부터. 맥락칩(경로·기기·OS·앱버전·시도단계) 자동첨부 → 재질문 0. [확인필요-가입수단 조회 API]

## 2. 💳 미납·결제·환불 — 2순위
**봇 발화**
- 진입 배너: "결제가 안 되시나요? 바로 도와드릴게요."
- 첫 안내: "결제·납부, 무엇을 도와드릴까요?"
- [결제가 안 돼요]: "다시 시도하다 막히셨군요. 어디서 멈췄는지만 알려주시면 금방 풀어드릴게요."
- 외부 결제창: "결제는 외부 결제창으로 잠깐 넘어갔다 돌아와요. 놀라지 마세요 😊"
- [반영 안 됨]: "보통 1~2분이면 반영돼요. 잠시 후에도 그대로면 바로 확인해 드릴게요."
- [환불]: "환불 도와드릴게요. 정확한 금액과 규정은 상담원이 확정해 드려요."

**버튼**: `미납·납부 현황 보기`·`결제가 안 돼요`·`가상계좌 확인하기`·`결제 문자 다시 받기`·`환불 문의하기` / `지금 결제하기` / `카드가 거절돼요`·`결제 화면이 멈춰요`·`얼마 내야 하죠`·`냈는데 반영이 안 돼요`·`다른 수단으로 결제하기`·`가상계좌로 받기`·`상담원 연결하기`
**카드**: "미납 현황"(미납 합계/항목/납부 기한, "기한 D-2") · "가상계좌 안내"(은행/계좌번호/금액/기한 → `계좌번호 복사하기`) · "환불 예상 안내"(시작일/회차/예상액 + "최종 금액은 상담원이 규정에 따라 확정해 드려요.")
**주의**: "이탈 막기" 아님 → "도와주기". 3.4회 재진입 다그치지 말 것. 금액 단정 금지. [확인필요-결제 외부모듈 콜백]

## 3. ✏️ 입반·등록·대기 — 3순위
**봇 발화**
- 첫 안내: "입반·대기, 무엇을 도와드릴까요?"
- 등록 정상: "등록 정상이에요 ✅ 다음 결제일도 함께 알려드릴게요."
- 결제 대기: "등록은 됐는데 결제가 남아 있어요. 지금 결제하면 확정돼요."
- 재수강 중: "재수강 신청이 접수됐어요. 확정되면 문자로 알려드릴게요."
- 대기 완료: "대기 걸어드렸어요. 자리가 나면 바로 문자로 알려드릴게요."
- 충원: "축하해요, 자리가 났어요! 결제까지 마치면 입반이 확정돼요."
- 반 바꾸기: "지금 반이 안 맞으셨군요. 더 맞는 대안을 먼저 찾아드릴게요."

**버튼**: `수강신청·입반하기`·`내 등록·재수강 확인하기`·`대기 번호 확인하기`·`대기 걸기`·`충원 자리 등록하기`·`반 바꾸기(전반)`·`입반 신청하기`·`자리 나면 알림 받기`·`지금 결제하기`
**카드**: "강좌 선택"(강좌/시간/잔여 좌석, "잔여 3석"/"마감(대기 가능)") · "내 등록 현황"(강좌/등록 상태/다음 결제일, "등록 완료"/"결제 대기"/"재수강 신청 중") · "대기 현황"(강좌/대기 번호/예상 충원 [확인필요])
**주의**: 충원=명확·신속. 예상순번 단정 금지. 조회 키는 강좌 단위.

## 4. 📡 라이브·교재·배송 — 4순위
**봇 발화**
- 첫 안내: "라이브·교재, 무엇을 도와드릴까요?"
- 복습영상: "복습 영상은 수업 다음 날 오전 9시에 열리고 7일간 볼 수 있어요."
- 배송: "교재 배송 현황 바로 보여드릴게요."
- 환불: "라이브 환불은 교재비 → 수강료 순서로 진행돼요. 차근차근 안내해 드릴게요."
- LIVE 입반: "라이브 신청은 라이브 사이트에서 마무리돼요. 순서대로 안내할게요."

**버튼**: `복습·추가영상 보기`·`교재 배송 조회하기`·`수강료·교재비 보기`·`환불·취소 문의하기`·`LIVE 입반하기`·`영상이 안 열려요`(→🔑)·`배송 추적하기`·`LIVE 사이트에서 결제하기`·`상담원 연결하기`
**카드**: "교재 배송 현황"(주문/상태/택배사/송장 "****1234") · "라이브 수강료·교재비"(수강료/교재비/기한)
**주의**: 라이브 별도 사이트 안내로 헛걸음 방지 [확인필요-연동]. 환불 "교재비→수강료" 순서 고정. 영상 오류는 계정·앱으로.

## 5. 📋 출결·보강 (조회) — 5순위
**봇 발화**
- 첫 안내: "출결·보강, 무엇을 확인할까요?"
- 보강 조회: "어떤 강좌, 몇 주차 보강인지 골라주시면 바로 보여드릴게요."
- 보강 카드: "이 회차 보강은 신청할 수 있어요. 영상은 수업 다음 날 오전 9시부터 7일간 볼 수 있어요."
- 출석: "오늘 출결 바로 확인해 드릴게요."
- 결석 신고: "접수됐어요. 담임 선생님 확인 후 처리돼요."

**버튼**: `동영상 보강 조회하기`·`오늘 출석 확인하기`·`결석·지각 미리 신고하기`·`동보 자료 받기`·`보강 신청하기`·`자료 문자 다시 받기`·`강좌 선택`→`주차·회차 선택`
**카드**: "보강 현황"(강좌/주차·회차/보강 상태/시청 기한/남은 보강 횟수, "신청 가능"/"신청 완료·7일 이내 시청") · "오늘 출결"("17:58 체크인 ✅"/"결석(보강 필요)"/"지각")
**주의**: 조회는 "강좌→주차·회차" 2단계. "문자 다시 받기" 항상 노출. 수강료 차감·지각 기준 [확인필요].

**버튼**: `자주 묻는 것 보기`·`상담원 연결하기`·`설명회·컨설팅 예약 보기`·`교재 수령 안내`·`○○ 가능한가요`·`언제예요·일정`·`어디예요·위치`·`예약 변경·취소하기`·`내 강좌 교재 조회하기`
**카드**: "내 예약"(종류/날짜·시간/장소) · "교재 수령 안내"(장소/운영 시간)
**주의**: 기타 28%(되나요/언제/어디) FAQ 흡수, 못 풀면 즉시 사람. 컴플레인: "불편을 드려 정말 죄송해요. 바로 상담원이 도와드릴게요." 최우선 큐, 추측 금지.

## 상담원 핸드오프 (3단계: 동의 → 접수번호 → 연결 후 안내)
**봇 발화**
- ① 동의: "상담원에게 이 내용 그대로 전달할게요. 다시 설명하지 않으셔도 돼요. 이대로 연결할까요?"
- ② 접수번호: "접수됐어요. 접수번호는 #A-2026-0617-031이에요. 순서대로 연결해 드릴게요."
- ③ 운영 중(평일 10–20시): "지금 상담 가능해요. 평균 약 ○분 정도 기다리시면 돼요."
- ③ 운영 외: "지금은 상담 시간이 아니에요. 오전 10시에 1순위로 연결해 드릴게요. 급하면 셀프 조회는 24시간 가능해요."
- 컴플레인 우선: "불편을 드려 정말 죄송해요. 가장 먼저 상담원에게 연결해 드릴게요."

**버튼**: `이대로 연결하기`·`내용 수정하기`·`급하면 전화 걸기`·`셀프로 먼저 확인하기`·`대기 걸어두기`
**카드**: "상담원에게 전달할 내용"(학생 김○○/문의 유형/직전까지 시도한 내용 + `☑ 위 내용을 상담원에게 전달하는 데 동의해요`) · "연결 대기"(접수번호/내 앞 대기 약 ○명/평균 약 ○분)
**주의**: 핵심 가치 "재질문 0"(맥락칩 자동첨부). 운영 외에도 막다른 길 금지(10시 1순위 + 셀프 24시간).
