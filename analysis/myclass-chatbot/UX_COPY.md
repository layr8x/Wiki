## 1. 📋 출결·보강 (attend)

옛 '입반·등록·대기' 메뉴가 삭제되며 **'입반 강좌 확인'이 이 메뉴로 흡수**됨.

**봇 발화 / 카드** (포맷 정본 = `기획서_v6_요약.md §3` 출결·보강)
- **오늘 출석 확인**: `오늘(M/D) 출석 현황이에요.` + 강좌블록 `%강좌명%` / `수업 %시작%~%종료%` / `출석 %QR태그시각%`. 출석 전 = `출석예정`. 수업 없음 = 고정문구. 버튼 `[이전][처음으로]`
- **강좌 선택**: `어떤 강좌를 확인할까요?` + 강좌칩 + 안내 `*입반 완료된 강좌만 노출 (입반 예정 제외)`. 없음 → `현재 입반 중인 강좌가 없어요.` 버튼 `[강좌 선택 버튼][이전][처음으로]`
- **강좌 선택 후**: `어떤 내용을 확인할까요?` + `[동영상 보강][타반보강][추가영상]`(항상 3개 고정)
  - **동영상 보강**: `%회차명% | 마이클래스(VOD) | 시청 기한 %시청기한% | %총시청%분 제공 (%시청완료%분 시청)`. 변형 = `영상 준비 중` · `연구실 동영상 | 연구실 문의` · `출석 처리됨`. 없음 → 고정문구.
  - **타반보강**: `%강좌명% 타반보강 가능 일정이에요.` + `%회차명% | %날짜%(%요일%) | %시작%~%종료% | %강의실%`. 없음 → "…없어요. 문의는 상담 연결 버튼으로" 버튼 **`[상담 연결][이전][처음으로]`**.
  - **추가영상**: `%회차명% | 지급일 %지급일% | 시청 기한 %시청기한% %상태%`. 없음 → 고정문구.
- **입반 강좌 확인**: `입반된 강좌 현황이에요.` + `%강좌명%`(완납이면 결제 버튼 없음·카드 반복). 없음 → `현재 입반된 강좌가 없어요.` 버튼 `[이전][처음으로]`

**주의**: 강좌 선택은 "입반 완료" 강좌만(입반 예정 제외). 강좌 선택 후 서브 = 동영상 보강/타반보강/추가영상 3개 고정. 타반보강 없음은 상담 연결로.

## 2. 💳 납부·결제 (pay)

**봇 발화 / 카드** (포맷 정본 = `기획서_v6_요약.md §3` 납부·결제)
- **납부 현황**: `%강좌명% 납부 현황이에요.` + **`[납부필요]` 섹션**(수강료 %회차%회 %금액%원 / 교재비 %교재명% %금액%원 / 합계 %합계%원 / 납부기한 %기한%) + **`[납부대기 or 가상계좌 입금 대기]` 섹션**(동일 구조). 버튼 `[납부하기][이전][처음으로]`. 전체 완납 → `모든 수강료가 납부 완료됐어요.`
- **결제 내역**: `최근 3개월 결제 내역이에요.` + `%결제일% | %강좌명% (외 N건) | %금액%원 | %수단%(%카드사%) | %상태%`. 상태 = `결제완료` / `부분환불(환불금액: %금액%원)`. 없음 → `결제 내역이 없어요.` 버튼 `[이전][처음으로]`

**주의**: "이탈 막기" 아님 → "도와주기". 금액 단정 금지. 납부 현황은 **납부필요 / 납부대기·가상계좌 2섹션**. 결제 내역 = 결제상태(완료·부분환불) + 외 N건. 결제일 화면 표기 `YY/MM/DD`(데이터 정본은 `YYYY-MM-DD`).

## 3. 📅 수업·시간표 (time)

**봇 발화 / 카드** (포맷 정본 = `기획서_v6_요약.md §3` 수업·시간표)
- **내 시간표**: `이번 주(M/D~M/D) 시간표예요.` + `%요일% %시작%~%종료% %강좌명% · %강의실%`(요일순). 없음 → 고정문구. 버튼 `[다음 주 보기][이전][처음으로]`
- **강좌별 전체 회차 일정**: 강좌 선택 → `%강좌명% 전체 일정이에요.` + `%회차명% | %날짜%(%요일%) | %시작%~%종료%` + `전체 N회 중 M회차 진행 중`. 없음 → `회차 일정 정보를 불러올 수 없어요.` 버튼 `[다른 강좌 보기][이전][처음으로]`
- **종강일 확인**: `강좌별 종강일이에요.` + `%강좌명% → YYYY-MM-DD` + "휴강·일정 변경은 상담실로…". 버튼 **`[상담 연결][이전][처음으로]`**.

**주의**: 잘 쓰는 기능 → 조회만 빠르게. 종강일은 데이터 조회 종료화면(만족도 노출), 휴강·변경만 상담 연결.

## 4. 🔁 전반 (overall) — 전반 가능한 강좌 확인하기

옛 '시간이 안 맞아요' 노드명이 **'전반 가능한 강좌 확인하기'**로 변경.

**봇 발화 / 카드** (포맷 정본 = `기획서_v6_요약.md §3` 전반)
- **강좌 선택**: `%강좌명% %요일% %시각% %정원/잔여%` 칩으로 강좌 선택.
- **전반 결과**: `%강좌명%의 다른 시간대 강좌예요.` + `%지점단과% - %강좌명% %요일% %시각%`(여러 지점, **지점단과별** 노출) + "반 변경 신청은 상담을 통해…". 없음 → `현재 %강사명% 선생님의 다른 시간대 강좌가 없어요…`. 버튼 **`[상담 연결][이전][처음으로]`**.

**주의**: 타시간대는 **지점단과별**로 노출. 반 변경 신청은 상담 연결.
