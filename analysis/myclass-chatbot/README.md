## 설계 근거 (한 줄)
**전화 상담과 디지털(앱·카톡) 상담은 정반대다.** 전화는 출결·입반이 1·2위, 디지털 오픈채팅은 **계정·로그인·앱(37.1%)** 이 1위. 챗봇은 앱 안에 사니까 **디지털 기준**으로 설계한다. (상세: `DATA_ANALYSIS.md`)

## 가이드 정직성 원칙
- 모든 자가해결 가이드는 `RESOLUTION_EVIDENCE.md`의 **실제 상담 해결행동만** 사용(허위 가이드 0).
- 조회 데이터가 없거나 불확실하면 단정하지 않고 **적절한 채널로 핸드오프**.
- 상담 **원문 텍스트**는 개인정보 보호로 깃허브에 올리지 않음 — 여기엔 집계·분류·분석만 둔다.
