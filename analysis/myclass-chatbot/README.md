## 한 줄 결론
**전화 상담과 디지털(앱·카톡) 상담은 정반대다.** 전화는 출결·입반이 1·2위, 디지털 오픈채팅은 **계정·로그인·앱(37.1%)** 이 압도적 1위. 챗봇은 앱 안에 사니까 **디지털 기준**으로 설계해야 한다.

## 검증으로 바로잡은 것
1. **결제 "이탈 61%" = 착시.** 실사용자 기준 결제완료 **81.6%**(정상). 외부 sdijeon 결제모듈 경유로 GA가 중간을 못 잡았고, 1인당 결제화면 3.4회 재진입으로 이벤트가 부풀려졌던 것.
2. **카톡 오픈채팅 상담을 분석에 추가**(이전 누락). → 계정·앱이 디지털 1위임을 확인.

## ⚠️ 여기 없는 것 (개인정보 보호)
상담 **원문 텍스트**(AMS `상담내용`, 카카오 메시지 본문)는 개인정보가 섞일 수 있어 **깃허브에 올리지 않음**. 원문은 **Supabase 잠금 테이블**에만 보관(카카오는 적재 완료, AMS 원문은 별도 승인 시 적재). 여기엔 **개인정보 없는 집계·분류·분석만** 둔다.
