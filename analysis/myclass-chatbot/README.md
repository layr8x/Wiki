## 설계 근거 (한 줄)
**전화 상담과 디지털(앱·카톡) 상담은 정반대다.** 전화는 출결·입반이 1·2위, 디지털은 **계정·로그인·앱**이 1위. 인앱 챗봇은 로그인 후에 사는데 그 수요는 로그인 전에 터져 못 닿으므로, **챗봇 흡수 타깃 = 전화의 출결·보강·결제·시간표**로 4메뉴를 배치했다. (상세: `DATA_ANALYSIS.md`)

## 가이드 정직성 원칙
- 모든 자가해결 가이드는 `RESOLUTION_EVIDENCE.md`의 **실제 상담 해결행동만** 사용(허위 가이드 0).
- 조회 데이터가 없거나 불확실하면 단정하지 않고 **적절한 채널로 핸드오프**.
- 상담 **원문 텍스트**는 개인정보 보호로 깃허브에 미반입 — 집계·분류·분석만 둔다.
